# 📘 版本管理系统完整使用指南

## 🎯 系统概览

版本管理系统为小说章节提供完整的版本控制、质量分析和对比工具，帮助作者管理和优化章节内容。

**核心功能**:
- 📝 快速编辑章节内容
- 💾 保存多个版本
- 🤖 AI 质量评分
- 🔍 版本差异对比
- ⭐ 选择最佳版本

---

## 🚀 快速开始

### 完整工作流

```
1. 选择章节
   ↓
2. 点击"编辑内容"
   ↓
3. 修改章节文本
   ↓
4. 点击"保存为新版本"
   ↓
5. 等待 AI 质量分析 (3-5秒)
   ↓
6. 查看评分和改进建议
   ↓
7. 点击"对比版本"
   ↓
8. 选择两个版本对比
   ↓
9. 查看差异高亮
   ↓
10. 选择最佳版本
```

---

## 📖 功能详解

### 1. 章节选择

**位置**: 页面右上角下拉菜单

**功能**:
- 快速切换章节
- 搜索章节 (按标题或章节号)
- 显示章节元信息 (字数、状态)

**操作**:
1. 点击章节选择器
2. 输入关键词搜索 (可选)
3. 选择目标章节
4. 版本列表自动加载

---

### 2. 内容编辑

**位置**: 点击"编辑内容"按钮后显示

**功能**:
- 全文编辑章节内容
- 实时字数统计
- 修改状态提示

**操作**:
1. 点击绿色"编辑内容"按钮
2. 在编辑器中修改文本
3. 观察字数和修改状态
4. 点击"保存为新版本"创建版本

**提示**:
- 📌 编辑器采用等宽字体，便于排版
- 📌 未修改内容时按钮自动禁用
- 📌 空内容无法保存

---

### 3. 版本保存

**按钮**: "保存为新版本" (蓝色，编辑器右上角)

**流程**:
```
点击按钮
  ↓
创建版本 (版本号自动递增)
  ↓
显示成功提示
  ↓
自动触发 AI 质量分析
  ↓
显示分析进度横幅
  ↓
分析完成 (3-5秒)
  ↓
版本列表刷新，显示评分
```

**状态指示器**:
- 🔵 蓝色横幅 + Loading 图标 = 分析中
- 🟢 绿色横幅 + 对号图标 = 分析完成
- 🔴 红色横幅 + 警告图标 = 分析失败 (版本已保存)

**注意**:
- ⚠️ 分析失败不影响版本保存
- ⚠️ 分析期间可继续编辑
- ⚠️ 每次保存消耗一定算力 (credits)

---

### 4. 质量评分

**显示位置**: 版本列表每个版本卡片

**评分维度**:
- **整体评分** (0-100 分)
- **剧情连贯性**
- **人物塑造**
- **对话质量**
- **描写细腻度**
- **节奏把控**

**评分解读**:
- 🟢 85-100 分 = 优秀
- 🟡 70-84 分 = 良好
- 🟠 60-69 分 = 及格
- 🔴 0-59 分 = 需改进

**改进建议**:
每个版本提供 3-5 条具体建议，例如:
- "对话过于生硬，可增加口语化表达"
- "人物情感变化需要更细腻的描写"
- "剧情转折过快，建议增加铺垫"

---

### 5. 版本对比

**启用**: 点击"对比版本"按钮

**操作步骤**:
1. 点击蓝色"对比版本"按钮
2. 版本列表显示复选框
3. 勾选第一个版本
4. 勾选第二个版本
5. 差异视图自动显示

**差异高亮**:
- 🟢 绿色背景 = 新增内容
- 🔴 红色背景 = 删除内容
- ⚪ 灰色文本 = 未变更内容

**统计信息**:
- 新增行数
- 删除行数
- 总变更行数

**退出对比**:
点击"退出对比"按钮，清空选择

**限制**:
- ⚠️ 最多选择 2 个版本
- ⚠️ 对比模式下无法编辑
- ⚠️ 对比模式下无法删除版本

---

### 6. 版本操作

#### 6.1 选择版本
**作用**: 设置当前版本为章节的"当前版本"

**操作**: 点击版本卡片的"选择此版本"按钮

**效果**:
- 当前版本标记为 ⭐ 已选中
- 其他版本的选中状态取消
- 章节内容更新为选中版本

#### 6.2 评分版本
**作用**: 用户手动评分 (1-5 星)

**操作**: 点击版本卡片的星星图标

**用途**:
- 标记个人偏好
- 辅助筛选最佳版本

#### 6.3 删除版本
**作用**: 永久删除版本

**操作**: 点击版本卡片的"删除"按钮

**确认**: 弹窗二次确认

**限制**:
- ⚠️ 已选中的版本无法删除
- ⚠️ 删除操作不可恢复

## 💡 使用技巧

### 技巧 1: 快速迭代优化

**场景**: 对同一段落进行多次优化

**方法**:
1. 编辑内容 → 保存版本 → 查看评分
2. 根据改进建议修改 → 再次保存版本
3. 对比新旧版本 → 选择评分更高的
4. 重复 2-3 次达到最佳效果

**优势**: 保留每次迭代的历史，可随时回退

### 技巧 2: A/B 测试风格

**场景**: 尝试不同的写作风格

**方法**:
1. 创建版本 A (严肃风格)
2. 创建版本 B (轻松风格)
3. 对比差异
4. 根据质量评分和个人偏好选择

### 技巧 3: 分段优化

**场景**: 长章节分段优化

**方法**:
1. 第一天: 优化前半部分 → 保存版本 1
2. 第二天: 优化后半部分 → 保存版本 2
3. 第三天: 整体润色 → 保存版本 3
4. 对比版本 1 和版本 3，查看整体提升

### 技巧 4: 评分趋势分析

**场景**: 观察写作水平变化

**方法**:
1. 按时间顺序查看版本评分
2. 找出评分最高的版本
3. 分析该版本的特点
4. 在后续写作中应用相同技巧

## ⚠️ 常见问题

### Q1: 为什么"保存为新版本"按钮禁用？

**可能原因**:
1. 内容未修改 (`isDirty=false`)
2. 内容为空
3. 正在保存中

**解决方法**:
- 修改章节内容后按钮自动启用
- 确保内容不为空

### Q2: 质量分析失败怎么办？

**现象**: 红色横幅提示"质量分析失败，但版本已保存"

**原因**:
- LLM Provider 配置错误
- API 调用失败
- 网络问题
- 算力余额不足

**解决方法**:
1. 检查算力余额
2. 稍后重试
3. 联系管理员检查 LLM Provider 配置

**注意**: 版本已成功保存，仅分析失败，不影响使用

### Q3: 为什么无法同时编辑和对比？

**设计原因**: 避免操作混乱，确保用户专注单一任务

**解决方法**:
- 编辑时点击"退出编辑"
- 对比时点击"退出对比"
- 切换到所需模式

### Q4: 版本列表为空？

**可能原因**:
1. 章节尚未创建任何版本
2. API 请求失败
3. 权限不足

**解决方法**:
1. 点击"编辑内容"创建第一个版本
2. 刷新页面
3. 检查浏览器控制台错误

### Q5: 如何删除所有版本？

**答案**: 无法批量删除，需逐个删除

**原因**: 防止误操作导致数据丢失

**建议**: 保留至少一个高质量版本

## 🔧 技术细节

### 自动刷新机制

**触发条件**:
- 创建新版本 → 刷新版本列表
- 质量分析完成 → 刷新版本列表
- 选择版本 → 刷新版本列表
- 删除版本 → 刷新版本列表

**刷新策略**: React Query 自动缓存和重新验证

### 性能优化

**Diff 计算**:
- 使用 `useMemo` 缓存结果
- 仅在版本 ID/内容变化时重新计算
- 目标: <200ms (10KB+ 文本)

**列表渲染**:
- 版本列表按创建时间倒序
- 支持 50+ 版本流畅滚动

### 数据流

```
用户操作
  ↓
React 组件状态更新
  ↓
React Query Mutation
  ↓
API 请求
  ↓
数据库更新
  ↓
React Query 缓存失效
  ↓
自动重新获取数据
  ↓
UI 更新
```
