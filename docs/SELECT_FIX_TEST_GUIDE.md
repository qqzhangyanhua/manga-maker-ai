## 常见问题

### Q1: 下拉菜单仍然不显示
**解决方案**:
1. 清除浏览器缓存 (Ctrl+Shift+Delete)
2. 强制刷新 (Ctrl+Shift+R)
3. 重启开发服务器 (`pnpm dev`)

### Q2: 样式不统一 (仍然是白色)
**解决方案**:
1. 检查是否有全局 CSS 覆盖
2. 检查 Tailwind CSS 是否正确加载
3. 运行 `pnpm run build` 重新构建

### Q3: 下拉菜单被截断
**解决方案**:
1. 检查 Dialog 是否设置了 `overflow: hidden`
2. 确认 `position="popper"` 属性存在
3. 调整 `sideOffset` 值
