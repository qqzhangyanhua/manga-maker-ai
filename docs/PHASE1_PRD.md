## 一、产品背景与目标

### 1.1 当前问题

通过对现有用户行为分析，我们发现以下痛点：

| 问题 | 影响 | 用户反馈频次 |
|------|------|-------------|
| 每次创建分镜需要从零开始，重复劳动多 | 创作效率低，单个项目耗时长 | 高 |
| 生成结果不满意时只能单个重新生成 | 浪费配额，体验差 | 高 |
| 修改后无法回退，误操作无法恢复 | 用户操作焦虑感强 | 中高 |
| 资产数量增多后难以查找和管理 | 资产利用率低，重复创建 | 中 |

### 1.2 产品目标

**核心目标**: 提升创作效率 300%，降低配额浪费 50%，提高资产复用率 200%

**关键成果指标 (OKR)**:
- KR1: 用户平均创作一个项目的时间从 60 分钟降至 20 分钟
- KR2: 模板使用率达到 70% (使用模板的用户占比)
- KR3: 批量生成功能使用率达到 40%
- KR4: 版本回退功能每周被使用 ≥ 500 次
- KR5: 搜索功能使用率达到 60% (通过搜索找到资产的占比)

### 1.3 目标用户

| 用户类型 | 占比 | 特点 | 核心诉求 |
|---------|------|------|---------|
| 轻度创作者 | 40% | 偶尔创作，经验不足 | 需要模板和指导，减少决策负担 |
| 中度创作者 | 45% | 经常创作，有一定经验 | 需要效率工具，快速迭代 |
| 重度创作者 | 15% | 专业创作者，大量作品 | 需要高级管理和复用能力 |

## 三、详细需求说明

### 3.1 分镜模板库

#### 3.1.1 功能概述

**问题**: 用户每次创建项目都需要从零开始设计分镜布局，效率低下，且新手不知道如何合理分镜。

**解决方案**: 提供预设分镜模板库，用户可直接应用模板快速创建，也可将自己的分镜组合保存为模板复用。

#### 3.1.2 用户故事

```
作为一名轻度创作者
我想要选择现成的分镜模板
以便快速开始创作，而不需要学习分镜知识

作为一名中度创作者
我想要保存自己常用的分镜布局
以便在未来的项目中复用

作为一名重度创作者
我想要在模板市场分享我的模板
以便获得其他用户的认可和收益
```

#### 3.1.3 功能详细说明

##### A. 模板创建与管理

**创建模板**:
- **触发点**: 在项目编辑器中，选中连续的 2-12 个分镜
- **操作**: 点击"保存为模板"按钮
- **输入字段**:
  - 模板名称 (必填, 2-32字符)
  - 模板描述 (选填, 0-200字符)
  - 适用场景标签 (多选: 对话/战斗/情感/转场/开场/结尾)
  - 可见性 (私有/公开)
- **保存内容**:
  - 分镜数量
  - 每个分镜的属性 (panel_type, camera_angle, shot_size, importance)
  - 相对位置关系
  - 不保存具体内容 (dialogue, character_name, image_url 等)

**模板列表**:
- **我的模板**: 显示用户创建的所有模板
- **官方模板**: 系统预设的高质量模板 (由管理员创建)
- **社区模板**: 其他用户公开分享的模板 (按点赞数排序)

**模板展示卡片**:
```
┌─────────────────────────────┐
│ 📐 模板缩略图 (3x2网格示意图)  │
├─────────────────────────────┤
│ 对话场景 - 3格标准布局          │
│ 👤 作者名 | ⭐ 128 | 📥 456    │
│ 标签: #对话 #日常              │
└─────────────────────────────┘
```

**模板操作**:
- **应用模板**: 插入到当前项目
- **编辑**: 修改模板属性 (仅自己的模板)
- **删除**: 删除模板 (仅自己的模板)
- **复制**: 复制到自己的模板库 (社区模板)
- **点赞**: 给社区模板点赞
- **预览**: 查看模板详情

##### B. 模板应用

**应用方式 1: 新建项目时应用**
- 在项目创建对话框增加"从模板创建"选项
- 选择模板后自动创建项目并生成对应数量的空白分镜
- 分镜属性继承模板，内容为空

**应用方式 2: 在现有项目中插入**
- 在项目编辑器中点击"插入模板"
- 选择插入位置 (某个分镜之后)
- 后续分镜自动重新排序

**应用方式 3: 替换现有分镜**
- 选中连续的 N 个分镜
- 点击"用模板替换"
- 选择 N 格模板
- 内容保留，只替换布局属性

##### C. 官方预设模板

**初始提供 12 个官方模板**:

| 模板名称 | 分镜数 | 适用场景 | 布局说明 |

| 对话标准-3格 | 3 | 对话 | 特写→近景→特写 |
| 对话标准-4格 | 4 | 对话 | 中景→特写→特写→近景 |

| 战斗基础-4格 | 4 | 战斗 | 全景→动作→特写→全景 |
| 战斗高潮-6格 | 6 | 战斗 | 远景→全景→动作→特写→动作→全景 |
| 情感爆发-3格 | 3 | 情感 | 近景→特写(大)→特写 |

##### D. 模板市场

**入口**: `/templates` 页面

**筛选器**:
- 分镜数量: 1-3格 / 4-6格 / 7-12格
- 场景类型: 对话 / 战斗 / 情感 / 转场 / 其他
- 排序: 最新 / 最热 / 点赞最多

**搜索**: 支持模板名称和描述全文搜索

**详情页**: 点击模板卡片进入详情
- 显示完整分镜布局图
- 显示每个分镜的属性详情
- 显示使用次数和用户评价
- "应用到我的项目"按钮

### 3.2 批量操作与变体生成

#### 3.2.1 功能概述

**问题**:
1. 用户生成图片时只能单个生成，效率低
2. 生成结果不满意时只能重新生成，无法比较选择
3. 调整参数后需要手动重新生成每个分镜

**解决方案**:
1. 支持批量选择多个分镜一键生成
2. 单个分镜支持生成 2-4 个变体供选择
3. 支持批量调整参数并重新生成

#### 3.2.2 用户故事

```
作为一名中度创作者
我想要一次性生成多个分镜的图片
以便节省时间，快速看到整体效果

作为一名重度创作者
我想要为同一个分镜生成多个变体
以便选择最满意的一个

作为一名轻度创作者
我想要调整风格后一键重新生成
以便尝试不同的视觉效果
```

#### 3.2.3 功能详细说明

##### A. 批量生成

**触发方式**:
- 方式 1: 在分镜列表中勾选多个分镜，点击"批量生成"
- 方式 2: 选择"全部生成"(生成所有未生成的分镜)

**生成逻辑**:
- 按分镜顺序依次生成 (串行)
- 显示实时进度条 (已生成 X / 总共 Y)
- 生成过程中可以取消
- 失败的分镜标记并跳过，继续生成下一个

**批量生成设置面板**:
```
┌─────────────────────────────┐
│ 批量生成设置                  │
├─────────────────────────────┤
│ 已选择: 12 个分镜             │
│ 预计消耗配额: 12 次           │
│                              │
│ 漫画风格: [下拉选择]          │
│ 生成质量: ● 标准  ○ 高质量   │
│ 失败处理: ● 跳过  ○ 停止     │
│                              │
│ [取消]  [开始生成]           │
└─────────────────────────────┘
```

**生成进度提示**:
```
┌─────────────────────────────┐
│ 正在生成 (7/12)              │
│ ████████░░░░░░ 58%           │
│                              │
│ ✓ 分镜1: 已完成               │
│ ✓ 分镜2: 已完成               │
│ ...                          │
│ ⏳ 分镜7: 生成中...           │
│ ⏸ 分镜8: 等待中               │
│                              │
│ [取消生成]                    │
└─────────────────────────────┘
```

##### B. 变体生成

**触发方式**:
- 在单个分镜卡片上点击"生成变体"按钮

**变体数量**:
- 默认生成 3 个变体
- 可选 2-4 个 (通过设置面板)

**变体策略**:
```typescript
变体1: 使用原始提示词
变体2: 提示词 + "different composition" (构图变化)
变体3: 提示词 + "different lighting" (光线变化)
变体4: 提示词 + "different angle" (角度变化)
```

**变体展示**:
```
┌─────────────────────────────────────────┐
│ 分镜 #5 - 变体选择                        │
├─────────────────────────────────────────┤
│ ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐│
│ │[图片1] │ │[图片2] │ │[图片3] │ │[图片4] ││
│ │ ⭐原图 │ │ 构图变化│ │ 光线变化│ │ 角度变化││
│ │[选择]  │ │[选择]  │ │[选择]  │ │[选择]  ││
│ └───────┘ └───────┘ └───────┘ └───────┘│
└─────────────────────────────────────────┘
```

**选择变体**:
- 点击"选择"按钮后，该变体替换当前分镜的图片
- 未选择的变体保存到"历史变体"供后续查看

##### C. 批量调整与重新生成

**触发方式**:
- 选中多个分镜，点击"批量编辑"

**可批量修改的属性**:
- 漫画风格
- 分镜类型 (panel_type)
- 机位角度 (camera_angle)
- 景别 (shot_size)
- 重要性 (importance)

**批量编辑面板**:
```

│                              │

**重新生成策略**:
- 应用修改: 只更新属性，不重新生成图片
- 应用并重新生成: 更新属性后自动批量生成

##### D. 生成队列管理

**队列状态**:
- 等待中 (pending)
- 生成中 (processing)
- 已完成 (completed)
- 失败 (failed)

**队列操作**:
- 暂停队列
- 恢复队列
- 取消队列
- 重试失败项

### 3.3 版本控制与历史记录

#### 3.3.1 功能概述

**问题**:
1. 用户修改后无法回退到旧版本
2. 误操作后无法恢复
3. 无法对比不同版本的差异

**解决方案**:
1. 自动保存版本快照
2. 手动创建版本检查点
3. 版本对比和一键回滚

#### 3.3.2 用户故事

```
作为一名中度创作者
我想要在每次重大修改前保存一个版本
以便修改不满意时可以回退

作为一名轻度创作者
我想要系统自动保存版本
以便误操作后可以恢复

#### 3.3.3 功能详细说明

##### A. 版本快照机制

**自动保存时机**:

- 批量生成完成后
- 应用模板后
- 批量编辑后

**手动保存**:

**版本内容**:
```typescript
interface ProjectVersion {
  // 项目基础信息
  title: string;
  description: string;
  style: string;

  // 分镜数据 (完整快照)

    prompt: string;

    content: string;

  };

└─────────────────────────────┘
```

**版本操作**:
- **查看**: 打开只读预览，不影响当前版本
- **恢复**: 将项目回滚到该版本 (不可逆，但会创建新版本)
- **对比**: 选择两个版本对比差异

##### C. 版本对比

**对比视图**:
```
┌─────────────────────────────────────────┐
│ 版本对比: v3 ←→ v5                       │
├─────────────────────────────────────────┤

│   v5: "我的第一个故事 - 修改版"  [已修改]│
│                                          │
│ 分镜数量:                                │
│   v3: 8 个分镜                           │
│   v5: 10 个分镜  [新增 2 个]             │
│                                          │
│ 分镜变化:                                │
│   ✓ 分镜1-6: 无变化                      │
│   ↻ 分镜7: 图片已更新                    │
│   + 分镜8: 新增                          │
│   ✗ 分镜8(v3): 已删除                    │
│   + 分镜9-10: 新增                       │
│                                          │

└─────────────────────────────────────────┘
```

**差异标识**:
- ✓ 无变化
- ↻ 已修改
- + 新增
- ✗ 删除

##### D. 版本管理策略

**存储策略**:
- 保留最近 30 个版本
- 标记版本永久保存
- 超过 30 个自动删除最旧的未标记版本

**存储优化**:
- 只存储变化的字段 (增量存储)
- 图片 URL 不重复存储 (引用方式)

**性能优化**:
- 版本数据压缩
- 懒加载历史版本
- 缓存最近 5 个版本
