# 九宫格分镜生成 - 快速开始指南

## 🚀 5 分钟快速上手

### 第一步：进入剧本详情页

1. 登录系统
2. 进入【我的项目】
3. 选择一个项目，点击进入剧本详情页
4. 确保至少创建了一个章节

### 第二步：打开九宫格对话框

在页面顶部操作区，找到【九宫格】按钮（橙色边框，Grid 图标），点击打开对话框。

> 💡 **提示**：如果看不到【九宫格】按钮，请先创建至少一个章节。

### 第三步：填写生成信息

#### 必填信息

**1. 选择目标章节**
- 从下拉列表中选择要生成分镜的章节

**2. 填写剧情概述**（至少 20 字符）

示例：
```
一个年轻的剑客在竹林中与敌人对峙。他缓缓拔出长剑，眼神坚定。
敌人从暗处现身，两人开始激烈交锋。剑光闪烁，竹叶纷飞。
最终剑客以一招制胜,敌人倒地。剑客收剑，转身离去。
```

#### 可选信息

**3. 画面主题**（可选）

用一句话概括氛围，例如：
- "竹林剑战"
- "紧张对峙"
- "温馨日常"
- "激烈战斗"

**4. 参考图 URL**（可选）

提供参考图片的 URL，系统会继承其风格：
```
https://example.com/reference-style.jpg
```

**5. 覆盖选项**（可选）
- ☐ 不勾选：追加到章节末尾（推荐）
- ☑ 勾选：删除现有分镜并重新生成

### 第四步：生成分镜

1. 点击【生成九宫格】按钮
2. 等待 10-30 秒（生成过程中会显示加载状态）
3. 生成成功后会显示提示
4. 页面自动刷新，显示新生成的 9 个分镜

### 第五步：查看和编辑

生成完成后：
1. 在【分镜】标签页查看生成的 9 个镜头
2. 点击任意镜头可以查看详情
3. 可以编辑描述、视觉提示词等内容
4. 可以为每个镜头生成图像

## 💡 最佳实践

### 1. 剧情概述撰写技巧

**✅ 好的示例**：
```
详细描述场景、人物、动作、情绪：
"深夜的竹林中，月光透过竹叶洒下斑驳的光影。
年轻剑客李明站在空地中央，手握长剑，警惕地环顾四周。
突然，一道黑影从竹林深处闪现..."
```

**❌ 不好的示例**：
```
过于简短或抽象：
"两个人打架"
"他们在说话"
```

### 2. 画面主题选择

**✅ 好的主题**：
- 具体且富有画面感
- 能够指导镜头风格
- 例如："竹林夜战"、"温馨告别"、"紧张追逐"

**❌ 不好的主题**：
- 过于抽象或宽泛
- 例如："好看"、"有趣"、"一般"

### 3. 参考图使用

**✅ 推荐的参考图**：
- 风格统一的概念图
- 清晰的角色设定图
- 具有明确色彩倾向的场景图

**❌ 不推荐的参考图**：
- 模糊不清的图片
- 风格混杂的拼图
- 与剧情无关的图片

### 4. 覆盖选项使用

**推荐做法**：
- 首次生成：不勾选覆盖（追加到末尾）
- 不满意时：勾选覆盖（重新生成）
- 测试调整：勾选覆盖（避免重复）

## ⚠️ 常见问题

### Q1: 为什么看不到【九宫格】按钮？

**A**: 请确保：
- 已登录系统
- 已进入剧本详情页
- 至少创建了一个章节

### Q2: 生成失败，提示"配额不足"？

**A**: 您的算力配额已用完，请：
- 充值算力配额
- 联系管理员增加配额

### Q3: 生成的镜头风格不一致？

**A**: 可能原因：
- 剧情概述不够详细
- 参考图 URL 无效或不清晰
- 建议重新生成，提供更详细的描述

### Q4: 生成时间太长？

**A**: 生成 9 个镜头通常需要 10-30 秒，这是正常的。如果超过 1 分钟：
- 检查网络连接
- 刷新页面重试
- 联系技术支持

### Q5: 可以修改生成的镜头吗？

**A**: 可以！生成后：
- 在分镜列表中点击任意镜头
- 编辑描述、视觉提示词等内容
- 保存修改

### Q6: 可以只重新生成某一个镜头吗？

**A**: 当前版本不支持单镜重新生成，需要：
- 勾选"覆盖现有分镜"
- 重新生成全部 9 个镜头
- 或者手动编辑单个镜头

## 🎯 进阶技巧

### 技巧 1：利用章节梗概

如果章节已有梗概（summary），可以直接复制到剧情概述中，然后：
- 增加具体的场景描述
- 补充人物动作细节
- 添加情绪和氛围描述

### 技巧 2：分段生成

对于复杂剧情，可以：
1. 将剧情分成多个场景
2. 为每个场景创建一个章节
3. 分别生成九宫格分镜
4. 最后合并或调整顺序

### 技巧 3：风格统一

为了保持整个故事的风格统一：
1. 准备一张主要的参考图
2. 在所有九宫格生成中使用同一张参考图
3. 保持画面主题的风格一致

### 技巧 4：迭代优化

第一次生成可能不完美，建议：
1. 先生成一次，查看效果
2. 根据结果调整剧情概述
3. 勾选"覆盖"重新生成
4. 重复 2-3 次直到满意

## 📊 效果对比

### 使用九宫格 vs 普通分镜

| 对比项 | 普通分镜 | 九宫格分镜 |
|--------|---------|-----------|
| 数量 | 可变（通常 6-8 个） | 固定 9 个 |
| 连续性 | 一般 | 强连续性 |
| 场景统一 | 可跨场景 | 同一场景 |
| 镜头语言 | 基础 | 电影级 |
| 风格一致性 | 一般 | 严格保证 |
| 适用场景 | 章节概览 | 单场景深度展现 |
| 生成时间 | 10-20 秒 | 15-30 秒 |

### 推荐使用场景

**使用九宫格**：
- ✅ 重要的单场景戏份
- ✅ 需要细腻展现的情感戏
- ✅ 复杂的动作场面
- ✅ 需要强调连续性的剧情

**使用普通分镜**：
- ✅ 快速生成章节概览
- ✅ 跨场景的剧情推进
- ✅ 简单的过渡场景
- ✅ 需要灵活调整数量
