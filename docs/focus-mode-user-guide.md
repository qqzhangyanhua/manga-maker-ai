# 专注模式使用指南

## 🎯 快速开始

### 进入专注模式
1. 在剧本详情页点击"进入专注模式"按钮
2. 或在分镜卡片上点击"专注编辑"图标
3. 自动跳转到全屏编辑界面

### 界面布局
```
┌──────────────┬────────────────────────┬──────────────┐
│              │                        │              │

│  导航列表    │     (中央)             │  (右侧)      │
│  (左侧)      │                        │              │
│              │                        │              │
└──────────────┴────────────────────────┴──────────────┘
```

## 🔥 新功能使用

### 1. 批量生成章节 ⚡

**位置**: 顶部工具栏右侧

**使用步骤**:
1. 点击"批量生成章节"按钮
2. 查看待生成分镜统计
3. 确认后点击"开始生成"
4. 等待进度完成

**智能筛选**:
- ✅ 只生成有提示词的分镜
- ✅ 跳过已有图片的分镜
- ✅ 显示预估时间和额度

**适用场景**:
- 新创建的章节需要批量生成
- 修改提示词后批量重新生成
- 快速完成整章创作

---

### 2. 历史记录管理 📜

**位置**: 预览区顶部工具栏

**使用步骤**:
1. 点击"历史记录"按钮
2. 浏览所有历史生成图片
3. 点击图片查看大图
4. 选择后点击"应用此图片"

**功能特性**:
- ✅ 查看所有历史版本
- ✅ 显示生成时间和提示词
- ✅ 应用历史图片为当前图片
- ✅ 下载单张图片
- ✅ 删除不需要的历史记录

**适用场景**:
- 对比不同版本效果
- 恢复之前生成的图片
- 清理不需要的历史记录

## 💡 使用技巧

### 高效编辑流程
1. **快速浏览**: 使用左侧导航快速定位分镜
2. **批量配置**: 先配置好参数，再批量生成
3. **对比优化**: 使用历史记录对比不同参数效果
4. **键盘操作**: 使用快捷键提升操作效率

### 参数调优建议
- **推理步数**: 50-70 适合大多数场景
- **引导强度**: 7-10 平衡质量和创意
- **参考图**: 2-3 张效果最佳
- **负面提示词**: 添加不想要的元素

### 批量生成最佳实践
1. 先生成 1-2 个分镜测试参数
2. 确认效果后再批量生成
3. 生成过程中不要关闭页面
4. 完成后检查失败的分镜并重新生成

## ⚠️ 常见问题

### Q: 批量生成失败怎么办？
**A**: 
- 检查网络连接
- 确认账户额度充足
- 查看失败分镜的错误提示
- 单独重新生成失败的分镜

### Q: 历史记录太多怎么办？
**A**: 
- 定期清理不需要的历史记录
- 只保留满意的版本
- 系统会自动限制历史记录数量

### Q: 生成速度慢怎么办？
**A**: 
- 降低推理步数（30-40）
- 减少参考图数量
- 避免高峰时段
- 使用更快的模型（Nano-Banana）

### Q: 保存失败怎么办？
**A**: 
- 检查网络连接
- 刷新页面重试
- 联系技术支持

## 🎨 进阶技巧

### 1. 风格一致性
- 使用相同的参考图
- 保持提示词结构一致
- 使用相同的模型和参数

### 2. 快速迭代
- 先生成草图（低步数）
- 满意后提高步数精修
- 使用历史记录快速对比

### 3. 批量优化
- 先修改所有分镜的提示词
- 一次性批量生成
- 统一风格和质量
