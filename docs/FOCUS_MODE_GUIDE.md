# 专注模式使用指南

## 功能概述

专注模式是一个全屏的三栏式分镜编辑界面，让你能够专注于单个分镜的精细创作。

## 设计理念

参考了主流 AI 创作工具的设计（如可灵 AI），采用三栏布局：
- **左栏**：章节分镜导航列表
- **中央**：大图预览区域
- **右栏**：配置面板（角色、提示词、模型参数）

## 使用方式

### 1. 进入专注模式

在剧本详情页，有两种方式进入专注模式：

#### 方式一：从页面头部进入
1. 确保已有分镜（至少一个）
2. 点击页面顶部的 **"专注编辑"** 按钮（紫色，带 Maximize2 图标）
3. 自动进入专注模式，并选中第一个分镜

#### 方式二：从分镜卡片进入（待实现）
- 在分镜卡片上点击"专注编辑"按钮
- 直接进入该分镜的编辑界面

### 2. 专注模式界面说明

#### 顶部工具栏
- **退出按钮**：返回列表模式
- **快捷键提示**：显示常用快捷键

#### 左侧导航（宽度：256px）
- 章节折叠列表
- 分镜缩略图
- 显示分镜序号和描述
- 点击切换到对应分镜
- 底部显示生成进度统计

#### 中央预览区（弹性布局）
- 顶部：分镜导航按钮（上一个/下一个）
- 中央：大图预览（最大化显示）
- 底部：分镜描述和提示词显示
- 生成中状态：显示进度动画

#### 右侧配置面板（宽度：320px）
- **分镜描述编辑**：修改分镜文字描述
- **AI 提示词编辑**：编辑图像生成提示词
- **出场角色选择**：多选角色（带缩略图）
- **图片模型选择**：
  - Nano-Banana-Pro
  - Nano-Banana
  - 图梦4.0
- **宽高比选择**：1:1, 16:9, 9:16, 4:3, 3:4
- **高级参数**：
  - 推理步数 (20-100)
  - 引导强度 (1-20)
  - 负面提示词
- **操作按钮**：
  - 生成图片（橙色主按钮）
  - 删除当前图片

### 3. 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `ESC` | 退出专注模式 |
| `Ctrl/Cmd + ←` | 上一个分镜 |
| `Ctrl/Cmd + →` | 下一个分镜 |
| `Ctrl/Cmd + Enter` | 生成图片 |

### 4. 工作流程

典型的工作流程如下：

```
1. 点击"专注编辑"进入专注模式
   ↓
2. 在左侧选择要编辑的分镜
   ↓
3. 在右侧配置：
   - 修改描述和提示词
   - 选择出场角色
   - 调整模型参数
   ↓
4. 点击"生成图片"
   ↓
5. 预览生成结果
   ↓
6. 继续编辑下一个分镜（使用快捷键快速切换）
   ↓
7. 完成后按 ESC 退出
```

## 与列表模式的对比

| 功能 | 列表模式 | 专注模式 |
|------|---------|---------|
| **适用场景** | 批量管理、总览 | 单个分镜精细编辑 |
| **预览大小** | 小卡片 | 全屏大图 |
| **配置方式** | 卡片内嵌 | 独立配置面板 |
| **批量操作** | ✅ 支持 | ❌ 不支持 |
| **专注度** | 低（容易分心） | 高（沉浸式） |
| **切换分镜** | 滚动查看 | 左侧快速导航 |
| **快捷键** | 无 | 丰富的快捷键 |

## 技术架构

### 文件结构

```
src/app/scripts/[id]/
├── components/FocusMode/
│   ├── index.tsx                 # 主入口
│   ├── FocusModeLayout.tsx       # 三栏布局
│   ├── ChapterPanelNav.tsx       # 左侧导航
│   ├── PanelPreviewCenter.tsx    # 中央预览
│   ├── PanelConfigSidebar.tsx    # 右侧配置
│   └── types.ts                  # 类型定义
├── contexts/
│   └── FocusModeContext.tsx      # 状态管理
└── page.tsx                      # 主页面（集成）
```

### 数据流

```
主页面 (page.tsx)
  ↓ 传递数据
FocusModeProvider (上下文)
  ↓ 提供状态和操作
三栏布局组件
  ├── 左侧导航：读取 panels/chapters
  ├── 中央预览：读取 currentPanel/isGenerating
  └── 右侧配置：读取 config/characters
```

### 复用现有 API

专注模式完全复用现有的 API 接口，无需新增后端代码：

- `GET /api/story/[id]` - 获取剧本数据
- `GET /api/panel/[id]` - 获取分镜详情
- `POST /api/panel/generate` - 生成分镜图片
- `PATCH /api/panel/[id]` - 更新分镜
- `DELETE /api/panel/[id]` - 删除分镜

## 常见问题

### Q1: 为什么进入专注模式后看不到分镜？
**A**: 确保至少有一个分镜。如果没有分镜，专注模式按钮会被隐藏。

### Q2: 修改描述和提示词后立即生成，为什么没有生效？
**A**: 需要先点击"保存修改"按钮（蓝色按钮），保存成功后再生成。

### Q3: 专注模式下能批量生成吗？
**A**: 不支持。专注模式专注于单个分镜的精细编辑。批量操作请使用列表模式。

### Q4: 快捷键在输入框中也会触发吗？
**A**: 不会。当焦点在输入框或文本域时，快捷键会被禁用，避免误触发。

### Q5: 退出专注模式会丢失未保存的修改吗？
**A**: 会！请在退出前确保点击"保存修改"按钮。未来版本会添加自动保存功能。
