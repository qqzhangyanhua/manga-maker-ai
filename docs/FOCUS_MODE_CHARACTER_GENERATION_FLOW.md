## 关键交互点说明

### 1. 生成按钮触发条件
- ✨ 按钮仅在角色**没有图片**时显示
- 位于角色卡片右下角
- 橙色背景 + Sparkles 图标
- Hover 时显示角色描述预览

### 2. 对话框展示信息
- **标题**: 明确显示"为 [角色名] 生成角色图片"
- **角色描述**: 灰色背景区域，显示完整描述
- **风格选择**: 下拉选择器，带图标和双语名称
- **提示信息**: 说明风格选择的作用

### 3. 生成状态反馈
- **生成中**: 按钮显示加载动画，禁用状态
- **成功**: Toast 通知 + 对话框显示预览
- **失败**: Toast 错误提示，对话框保持打开

### 4. 数据自动刷新
- 生成成功后调用 `refetchAll()`
- 更新角色列表缓存
- 角色卡片自动显示新图片
- 无需用户手动刷新

## 技术栈

- **UI 框架**: React + TypeScript
- **对话框**: Radix UI Dialog
- **表单**: Radix UI Select
- **状态管理**: React Hooks (useState, useEffect)
- **数据获取**: fetch API + React Query (缓存)
- **通知**: Toast (shadcn/ui)
- **样式**: Tailwind CSS

## 错误场景处理

| 场景 | 处理方式 |
|------|---------|
| 配额已用完 | Toast 提示配额信息，不关闭对话框 |
| 网络错误 | Toast 错误提示，保持对话框打开 |
| 角色描述为空 | 仍可生成，使用角色名称作为提示词 |
| 取消操作 | 清空状态，关闭对话框 |
| 生成中关闭 | 禁止关闭，必须等待完成 |

## 性能优化

1. **懒加载**: 风格列表仅在对话框打开时加载
2. **缓存**: 风格列表使用 state 缓存
3. **节流**: 防止重复提交生成请求
4. **智能刷新**: 仅刷新必要的数据查询

## 用户体验优化

1. **即时反馈**: 每个操作都有明确的视觉反馈
2. **加载状态**: 生成时显示动画，告知用户进度
3. **错误友好**: 错误信息清晰，提供解决方案
4. **自动关闭**: 成功后短暂延迟自动关闭
5. **预览展示**: 生成结果立即预览，增强信心
