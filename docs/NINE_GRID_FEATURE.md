# 九宫格分镜生成功能文档

## 功能概述

九宫格分镜生成功能允许用户根据剧情概述、画面主题和参考图，生成一组具有清晰叙事推进关系的 3×3 九宫格分镜提示词文本，共 9 个连续镜头。

## 核心特性

### 1. 场景与时间统一
- 全部 9 个镜头发生在同一场景与同一时间轴内
- 镜头之间存在明确的前后承接关系
- 形成连续的动作、视线或情绪推进

### 2. 电影镜头语言
- 自然涵盖远景、中景、近景、特写等不同景别
- 灵活使用正视、侧视、背视、过肩、俯仰等视角变化
- 镜头景别与角度由剧情发展自动选择
- 具备真实影视分镜的流动感

### 3. 视觉一致性
- 人物外观、服装、体型比例保持一致
- 整体色彩倾向与光照条件统一
- 仅允许人物动作、姿态及镜头角度变化
- 不出现角色变形、风格断裂等问题

## 使用方法

### 1. 打开九宫格对话框

在剧本详情页面（`/scripts/[id]`）的头部操作区，点击【九宫格】按钮。

> **注意**：只有在已创建章节的情况下，【九宫格】按钮才会显示。

### 2. 填写生成参数

#### 必填字段

- **目标章节**：选择要生成分镜的章节
- **剧情概述**：详细描述场景中发生的事情（至少 20 字符）
  - 包括人物、动作、情绪等关键信息
  - 建议 100-500 字符，提供足够的上下文

#### 可选字段

- **画面主题**：用一句话概括这组分镜的整体氛围或主题
  - 例如："紧张对峙"、"温馨日常"、"激烈战斗"
  
- **参考图 URL**：提供参考图片的 URL
  - 系统会继承其人物外观、服装风格、色彩倾向和美术气质
  - 在所有 9 个镜头中保持一致
  
- **覆盖现有分镜**：勾选后将删除该章节的所有现有分镜
  - 不勾选则会追加到章节末尾

### 3. 生成结果

点击【生成九宫格】按钮后：

1. 系统调用 AI 生成 9 个连续分镜
2. 每个分镜包含：
   - 详细描述（150-200 字）
   - 视觉提示词（用于后续生图）
   - 镜头角度（正视/侧视/背视/过肩/俯视/仰视）
   - 景别（远景/全景/中景/近景/特写）
   - 分镜类型（action/dialogue/emotion/transition）
   - 重要性（high/medium/low）
3. 生成的分镜自动保存到数据库
4. 页面刷新后显示新生成的分镜

## 技术实现

### 文件结构

```
src/
├── lib/
│   └── nine-grid-generator.ts          # 九宫格生成核心逻辑
├── app/
│   ├── api/
│   │   └── chapter/
│   │       └── [id]/
│   │           └── generate-nine-grid/
│   │               └── route.ts         # API 路由
│   └── scripts/
│       └── [id]/
│           ├── page.tsx                 # 主页面（集成对话框）
│           └── components/
│               ├── NineGridDialog.tsx   # 九宫格对话框组件
│               ├── ScriptPageHeader.tsx # 头部组件（添加按钮）
│               └── ScriptPageTopBar.tsx # 顶部栏组件
```

### API 接口

**端点**：`POST /api/chapter/[id]/generate-nine-grid`

**请求体**：
```json
{
  "project_id": "string (required)",
  "plot_summary": "string (required, min 20 chars)",
  "theme": "string (optional)",
  "reference_image": "string (optional, URL)",
  "overwrite": "boolean (optional, default: false)"
}
```

**响应**：
```json
{
  "success": true,
  "panels": [
    {
      "id": "string",
      "panel_order": 1,
      "description": "string",
      "visual_prompt": "string",
      "camera_angle": "string",
      "shot_size": "string",
      "panel_type": "string",
      "importance": "string"
    }
    // ... 共 9 个
  ],
  "message": "成功为章节\"XXX\"生成 9 个九宫格分镜"
}
```

### 系统提示词

九宫格生成使用专门的系统提示词（`NINE_GRID_SYSTEM_PROMPT`），强调：

1. 场景与时间统一性
2. 电影镜头语言的灵活运用
3. 场景与人物细节的自动补全
4. 参考图风格的严格继承
5. 视觉一致性保证
6. 输出格式规范

### 配额与权限

- 使用 `script_analyzer` 类型的 LLM Provider
- 消耗用户算力配额（通过 `assertAndIncrementUsage` 检查）
- 需要用户登录和章节所有权验证
- 生成日志记录到 `generation_log` 表

## 使用示例

### 示例 1：动作场景

**剧情概述**：
```
一个年轻的剑客在竹林中与敌人对峙。他缓缓拔出长剑，眼神坚定。
敌人从暗处现身，两人开始激烈交锋。剑光闪烁，竹叶纷飞。
最终剑客以一招制胜，敌人倒地。剑客收剑，转身离去。
```

**画面主题**：竹林剑战

**生成结果**：9 个连续镜头，从远景建立环境，到中景展示对峙，近景捕捉表情，特写强调剑光，最后回到远景收尾。

### 示例 2：情感场景

**剧情概述**：
```
一对情侣在咖啡馆里坐着。女孩低头不语，男孩试图安慰她。
女孩抬起头，眼中含泪。男孩伸手握住她的手。
女孩终于露出微笑，两人相视而笑。
```

**画面主题**：和解时刻

**参考图**：https://example.com/couple-style.jpg

**生成结果**：9 个连续镜头，严格继承参考图的人物外观和色彩风格，通过不同景别和角度展现情感变化。

## 注意事项

### 1. 输入质量
- 剧情概述越详细，生成效果越好
- 建议包含具体的场景、人物、动作、情绪描述
- 避免过于抽象或模糊的描述

### 2. 参考图使用
- 参考图 URL 必须可访问
- 建议使用清晰、风格统一的参考图
- 参考图会影响所有 9 个镜头的视觉风格

### 3. 生成时间
- 生成 9 个镜头通常需要 10-30 秒
- 请耐心等待，不要重复点击
- 生成过程中会显示加载状态

### 4. 结果调整
- 生成后可以在分镜编辑器中调整单个镜头
- 支持重新生成（勾选"覆盖现有分镜"）
- 建议先预览结果再决定是否保留

## 与现有功能的区别

| 特性 | 普通分镜生成 | 九宫格生成 |
|------|------------|-----------|
| 数量 | 可变（默认 6） | 固定 9 个 |
| 场景 | 可跨场景 | 同一场景 |
| 时间轴 | 可跨时间 | 同一时间轴 |
| 连续性 | 一般连续 | 强连续性 |
| 输入 | 章节梗概 | 剧情概述/主题/参考图 |
| 镜头语言 | 基础 | 电影级 |
| 风格一致性 | 一般 | 严格保证 |

## 故障排除

### 问题：生成的镜头数量不是 9 个

**原因**：AI 返回的结果不符合预期

**解决**：
- 检查剧情概述是否足够详细
- 尝试调整描述方式
- 联系管理员检查 LLM Provider 配置

### 问题：生成失败，提示配额不足

**原因**：用户算力配额已用完

**解决**：
- 充值算力配额
- 联系管理员增加配额

### 问题：生成的镜头风格不一致

**原因**：参考图未正确应用或描述不够明确

**解决**：
- 确保参考图 URL 有效
- 在剧情概述中明确描述人物外观
- 尝试使用更具体的画面主题
