# 九宫格分组生成与角色参考图选择功能

## 功能概述

本功能优化了九宫格生成工作流,主要包括:

1. **自动分组展示**: 镜头按每9个一组自动分组
2. **快速生成**: 每组提供"生成九宫格"按钮,一键选中该组镜头
3. **角色参考图**: 生成时可选择角色参考图,确保角色一致性

## 使用指南

### 1. 分组展示

在镜头详情面板中,镜头会自动按9个一组分组展示:

- 第1组: 镜头1-9
- 第2组: 镜头10-18
- 第3组: 镜头19-27
- ...

每组显示:
- 组标题（第X组）
- 镜头范围（镜头X-Y）
- 完整性标记（不足9个时显示）
- "生成九宫格"按钮（不足9个时禁用）

### 2. 生成九宫格

点击"生成九宫格"按钮后:

1. 自动选中该组的9个镜头
2. 打开生成对话框
3. 显示九宫格预览
4. 显示角色参考图选择区（可选）

### 3. 选择角色参考图

在生成对话框中:

1. 系统自动检测章节关联的角色
2. 每个角色显示一个卡片
3. 点击"选择参考图"打开选择器
4. 选择器包含4个标签页:
   - 角色头像: 角色库的头像图片
   - 镜头图片: 项目中已生成的镜头图片
   - 场景库: 场景库图片
   - 最终分镜: Final 节点图片
5. 选择图片（最多5张）并确认
6. 选中的参考图显示在角色卡片下方

### 4. 提交生成

配置完成后:

1. 填写剧情概述（可选）
2. 选择漫画风格
3. 点击"开始生成"
4. 系统将角色参考图传递给 AI 生成服务

## 技术实现

### 核心组件

- `ShotGroupSection`: 单个9镜头分组
- `CharacterReferenceSection`: 角色参考图区域
- `CharacterReferenceCard`: 单个角色卡片
- `ReferenceImagePicker`: 参考图选择器

### API 端点

- `GET /api/canvas/chapter/:chapterId/characters`: 获取章节角色
- `GET /api/canvas/project/:projectId/reference-images`: 获取项目参考图
- `POST /api/canvas/nine-grid/generate`: 生成九宫格（扩展）

### 数据流

1. 用户点击"生成九宫格"
2. 系统查询章节角色列表
3. 用户选择参考图
4. 系统查询项目所有参考图
5. 用户确认选择
6. 提交生成请求（包含 characterReferences）
7. 后端调用 AI 生成服务

## 注意事项

1. 不足9个镜头的组无法生成九宫格
2. 角色参考图为可选功能
3. 每个角色最多选择5张参考图
4. 参考图会影响生成结果的角色一致性
