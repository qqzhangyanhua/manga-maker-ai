## 技术实现亮点

### 1. 类型安全
- 所有 Mock 数据都有明确类型定义
- 零 `any` 类型使用
- 遵循 TypeScript strict 模式

### 2. Mock 策略
- 使用 `vi.hoisted()` 确保 Mock 在模块导入前初始化
- 依赖注入式 Mock（Prisma, Auth, Mailer）
- 事务 Mock 支持复杂业务逻辑测试

### 3. 代码组织
- 共享测试工具避免重复
- 每个测试文件 < 400 行
- 清晰的测试分组（describe 嵌套）

### 4. 边界条件覆盖
- 正常路径（Happy Path）
- 异常路径（Error Path）
- 边界值测试（空值、最小/最大长度）
