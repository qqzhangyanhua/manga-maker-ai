# 角色形象图片维护指南

## 📍 角色图片维护的位置

### 1. 主要入口：资产库页面（Assets Library）

**访问路径**:
```
首页 → 导航栏"资产库" → 角色标签页
或直接访问: http://localhost:3000/assets?tab=characters
```

**功能概览**:
- ✅ 查看所有角色
- ✅ 创建新角色
- ✅ 编辑角色详情
- ✅ 管理角色的所有资产（图片、三视图、表情、服装）
- ✅ 删除角色

---

## 🎨 角色资产类型

### 1. 基础图片（Base Image）
- **位置**: 角色详情页 → 头部区域
- **用途**: 角色的主要参考图，展示角色的基本形象
- **操作**:
  - 📤 **上传自定义图片**: 点击头像区域的上传按钮
  - 🎨 **AI 生成**: 点击"生成基础图片"按钮
  - 🔄 **重新生成**: 如果已有图片，点击"重新生成"

### 2. 三视图（Three Views）
- **位置**: 角色详情页 → "三视图"标签页
- **类型**: 正面、侧面、背面
- **用途**: 为后续生成提供多角度参考
- **操作**:
  - 📤 **批量上传**: 点击"上传三视图"按钮
  - 🎨 **AI 生成**: 点击"生成三视图"按钮（基于基础图片）
  - 📷 **单独上传**: 点击每个视图的上传按钮
  - 🔄 **重新生成**: 点击每个视图的重新生成按钮

### 3. 表情矩阵（Expression Matrix）
- **位置**: 角色详情页 → "表情矩阵"标签页
- **类型**: 9种表情（中性、开心、悲伤、愤怒、惊讶、害怕、厌恶、思考、兴奋）
- **用途**: 为漫画分镜提供不同情绪的角色形象
- **操作**:
  - 🎨 **批量生成**: 点击"生成表情矩阵"按钮
  - 📤 **单独上传**: 点击每个表情的上传按钮
  - 🔄 **重新生成**: 点击每个表情的重新生成按钮

### 4. 服装库（Wardrobe）
- **位置**: 角色详情页 → "服装"标签页
- **类型**: 默认装、战斗装、休闲装、正式装等
- **用途**: 为不同场景提供角色的不同着装
- **操作**:
  - ➕ **创建新服装**: 点击"添加服装"按钮
  - 📤 **上传服装图片**: 在服装卡片上点击上传
  - 🎨 **AI 生成服装**: 在服装卡片上点击生成
  - 🗑️ **删除服装**: 在服装卡片上点击删除

## 🔄 完整的角色图片管理流程

### 方案 A: 从资产库创建和管理（推荐）

**适用场景**: 需要完整管理角色的所有资产

#### 步骤 1: 创建角色
1. 访问 `http://localhost:3000/assets`
2. 点击右上角的 **"创建角色"** 按钮
3. 填写角色信息：
   - 角色名称（必填）
   - 角色描述（必填）
   - 基础提示词（可选，用于 AI 生成）
   - 选择漫画风格（可选）
   - 标签（可选）

#### 步骤 2: 上传或生成基础图片
1. 角色创建成功后，自动进入角色详情页
2. 在顶部角色头像区域：
   - **选项 A**: 点击 📤 "上传图片" → 选择本地图片文件
   - **选项 B**: 点击 🎨 "生成基础图片" → AI 根据描述生成

#### 步骤 3: 生成或上传三视图
1. 切换到 **"三视图"** 标签页
2. **批量生成**（推荐）:
   - 点击 "生成三视图" 按钮
   - AI 基于基础图片生成正面、侧面、背面三张图
3. **单独上传**:
   - 点击每个视图卡片的上传按钮
   - 分别上传正面、侧面、背面图片

#### 步骤 4: 生成表情矩阵
1. 切换到 **"表情矩阵"** 标签页
2. **批量生成**（推荐）:
   - 点击 "生成表情矩阵" 按钮
   - AI 生成 9 种表情的角色形象
3. **单独上传/生成**:
   - 点击每个表情卡片
   - 选择上传或生成单个表情

#### 步骤 5: 创建服装
1. 切换到 **"服装"** 标签页
2. 点击 **"添加服装"** 按钮
3. 填写服装信息：
   - 服装名称（如"战斗装"、"休闲装"）
   - 服装类型（默认、战斗、休闲、正式等）
   - 服装描述
4. 生成或上传服装图片

---

### 方案 B: 从无限画布快速准备（新功能）

**适用场景**: 在创作流程中快速准备角色，重点是基础图片

#### 步骤 1: 在无限画布中打开角色准备抽屉
1. 访问时间线画布页面
2. 点击左上角的 👥 **"角色准备"** 按钮
3. 查看"待升级的小说角色"列表

#### 步骤 2: 升级小说角色
1. 点击角色卡片的 **"升级为角色资产"** 按钮
2. 在对话框中选择是否 **"立即生成基础图片"**
3. 点击 **"确认升级"**

#### 步骤 3: 补充其他资产（可选）
1. 升级完成后，角色出现在"章节角色"区域
2. 如果需要完整的资产（三视图、表情、服装）：
   - 方式 A: 在角色准备抽屉中点击 **"重新生成"** 按钮（仅基础图片）
   - 方式 B: 关闭抽屉，前往资产库进行完整管理

## 📋 各种图片操作的详细说明

### 1. 上传本地图片

**支持的格式**: JPG, PNG, WEBP
**最大文件大小**: 4MB

**操作步骤**:
1. 点击任意图片区域的 📤 "上传"按钮
2. 在弹出的 **ImageUploadDialog** 对话框中：
   - 点击虚线区域或拖拽文件
   - 选择本地图片文件
3. 图片预览显示后，点击 **"确认上传"**
4. 等待上传完成（显示进度条）
5. 上传成功后图片立即显示

**上传位置**:
- 基础图片 → MinIO: `characters/{characterId}/base_image_{timestamp}.png`
- 三视图 → MinIO: `characters/{characterId}/views/{viewType}_{timestamp}.png`
- 表情 → MinIO: `characters/{characterId}/expressions/{expressionType}_{timestamp}.png`
- 服装 → MinIO: `characters/{characterId}/outfits/{outfitId}_{timestamp}.png`

---

### 2. AI 生成图片

**前置条件**: 需要配置 LLM Provider 和图片生成服务

**生成参数**:
- 基于角色的 `base_prompt`（基础提示词）
- 基于角色的 `description`（描述）
- 基于漫画风格的 `prompt_prefix`（风格前缀）
- 图片尺寸: 512x768（角色生成）

**操作步骤**:

#### 生成基础图片
1. 在角色详情页顶部，点击 🎨 **"生成基础图片"** 按钮
2. API 调用: `POST /api/character/{characterId}/regenerate-image`
3. 生成时间: 约 10-30 秒
4. 生成完成后自动更新显示

#### 生成三视图
1. 在"三视图"标签页，点击 **"生成三视图"** 按钮
2. API 调用: `POST /api/character/generate-views`
3. 同时生成正面、侧面、背面三张图
4. 生成时间: 约 30-60 秒

#### 生成表情矩阵
1. 在"表情矩阵"标签页，点击 **"生成表情矩阵"** 按钮
2. API 调用: `POST /api/character/generate-expressions`
3. 同时生成 9 种表情
4. 生成时间: 约 60-120 秒

---

### 3. 重新生成图片

**用途**: 如果对当前图片不满意，可以重新生成

**操作步骤**:
1. 在任意已有图片的位置，点击 🔄 **"重新生成"** 按钮
2. 确认对话框弹出，点击 **"确认"**
3. 等待生成完成
4. 新图片替换旧图片

**注意事项**:
- ⚠️ 重新生成会覆盖原图片（无法恢复）
- ⚠️ 会消耗算力积分
- ✅ 可以多次生成，直到满意为止

## 🎯 不同场景的最佳实践

### 场景 1: 快速开始创作（小说转漫画）

**推荐流程**:
1. ✅ 在无限画布使用"角色准备"抽屉
2. ✅ 升级小说角色时选择"立即生成基础图片"
3. ✅ 基础图片足够支持初步创作
4. ⏳ 后续在资产库补充三视图和表情（可选）

**优点**: 快速、简单，立即可用
**缺点**: 资产不完整，高级功能受限

---

### 场景 2: 精细化角色管理

**推荐流程**:
1. ✅ 在资产库创建角色
2. ✅ 上传高质量的基础图片（手绘或照片）
3. ✅ 生成三视图
4. ✅ 生成表情矩阵
5. ✅ 创建多套服装

**优点**: 资产完整，支持所有功能
**缺点**: 需要更多时间和算力

---

### 场景 3: 混合方案（推荐）

**推荐流程**:
1. ✅ 在无限画布快速升级主要角色（生成基础图片）
2. ✅ 在资产库为主要角色补充三视图
3. ✅ 在创作过程中按需生成表情
4. ⏳ 配角可以仅保留基础图片

**优点**: 平衡效率和质量
**缺点**: 需要在两个界面切换

## 📊 角色资产状态说明

在 **CharacterPreparationDrawer** 中，会显示角色的准备状态：

### 状态指示器

**✅ 已准备**（绿色对勾）:
- 有基础图片（`base_image_url` 不为 null）
- 或有参考图片（`reference_image` 不为 null）

**⚠️ 缺失图片**（黄色警告）:
- 基础图片和参考图片都为 null
- 显示"重新生成"按钮

### 完整度等级

在资产库的角色详情页，会显示更详细的资产完整度：

1. **基础级**（⭐）:
   - ✅ 有基础图片或参考图片
   - ❌ 无三视图
   - ❌ 无表情矩阵

2. **标准级**（⭐⭐）:
   - ✅ 有基础图片
   - ✅ 有三视图（≥3张）
   - ❌ 无表情矩阵

3. **完整级**（⭐⭐⭐）:
   - ✅ 有基础图片
   - ✅ 有三视图（3张）
   - ✅ 有表情矩阵（≥6种）
   - ✅ 有服装（≥1套）

## 🔗 相关 API 端点

### 角色管理
- `GET /api/character` - 获取角色列表
- `GET /api/character/{id}` - 获取角色详情
- `POST /api/character` - 创建角色
- `DELETE /api/character/{id}` - 删除角色

### 图片生成
- `POST /api/character/{id}/regenerate-image` - 重新生成基础图片
- `POST /api/character/generate-views` - 生成三视图
- `POST /api/character/generate-expressions` - 生成表情矩阵

### 角色升级（无限画布）
- `POST /api/canvas/chapter/{id}/characters/upgrade` - 升级小说角色

### 服装管理
- `POST /api/character/outfits` - 创建服装
- `PATCH /api/character/outfits/{id}` - 更新服装
- `DELETE /api/character/outfits/{id}` - 删除服装

## 💡 常见问题

### Q1: 角色准备抽屉和资产库有什么区别？

**角色准备抽屉**（无限画布内）:
- 🎯 **目的**: 快速准备章节需要的角色
- ✅ **功能**: 升级小说角色、生成基础图片、补充缺失图片
- ⚡ **优点**: 快速、便捷、集成在创作流程中
- ❌ **限制**: 仅支持基础图片，不支持三视图/表情/服装

**资产库**:
- 🎯 **目的**: 完整管理所有角色资产
- ✅ **功能**: 创建角色、上传/生成所有类型图片、管理服装
- ⚡ **优点**: 功能完整、资产管理专业
- ❌ **限制**: 需要离开无限画布

### Q2: 我可以上传自己的图片吗？

✅ **可以**！所有图片位置都支持上传：
- 基础图片
- 三视图（正面、侧面、背面）
- 表情矩阵（9种表情）
- 服装图片

### Q3: AI 生成的图片不满意怎么办？

有以下选项：
1. 🔄 **重新生成**: 点击"重新生成"按钮，AI 会生成新图片
2. 📤 **上传替换**: 上传你自己的图片替换 AI 生成的
3. ✏️ **修改提示词**: 在角色设置中修改 `base_prompt`，然后重新生成

### Q4: 为什么有些角色显示"缺失图片"？

可能的原因：
1. 角色是从小说升级的，且没有选择"立即生成基础图片"
2. 图片生成失败（网络错误、LLM Provider 配置问题）
3. 手动创建的角色，尚未上传或生成图片

**解决方法**:
- 在角色准备抽屉中点击"重新生成"按钮
- 或前往资产库上传/生成图片

### Q5: 图片存储在哪里？

所有图片存储在 **MinIO 对象存储** 中：
- Bucket: `input-image`
- 路径格式: `characters/{characterId}/{类型}_{时间戳}.png`
- 访问方式: 通过 `base_image_url` 字段的 URL 访问

## 🚀 总结

### 维护角色形象图片的两种方式

| 方式 | 位置 | 适用场景 | 支持的操作 |
|------|------|---------|----------|
| **角色准备抽屉** | 无限画布 → 👥 按钮 | 快速准备章节角色 | 升级、生成基础图片、重新生成 |
| **资产库** | 导航栏 → 资产库 → 角色 | 完整管理角色资产 | 创建、上传、生成所有类型图片 |

### 推荐工作流程

1. **初次创建**: 在无限画布使用"角色准备"快速升级小说角色
2. **补充资产**: 前往资产库为重要角色生成三视图和表情
3. **日常维护**: 在资产库管理角色图片和服装
4. **快速修复**: 在无限画布的角色准备抽屉重新生成缺失图片
