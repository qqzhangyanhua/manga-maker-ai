# 剧本页面用户体验优化设计

> 设计日期：2026-02-02
> 状态：已确认，待实施

## 背景

剧本详情页（`/scripts/[id]`）是漫画创作的核心页面，承载「章节 → 分镜 → 漫画」的完整流程。当前用户在操作效率和内容预览方面存在痛点：

1. **操作效率低** - 编辑分镜需打开对话框，调整顺序不便
2. **内容预览困难** - 难以一眼看到整个故事的视觉节奏

## 设计方案

采用 **渐进式增强** 策略，在现有 Tab 结构基础上分阶段交付三个核心功能。

---

## 功能一：Inline 编辑分镜

### 目标

在分镜卡片上直接编辑，无需打开对话框。

### 交互流程

1. **悬停态** - 鼠标悬停时显示「编辑」图标按钮
2. **点击进入编辑** - 点击后，文本区域变为可编辑的 textarea
3. **自动保存** - 失焦或按 `Cmd+Enter` 时自动保存，显示保存状态
4. **取消编辑** - 按 `Esc` 取消，恢复原内容

### 可编辑字段

| 字段 | 说明 | 优先级 |
|------|------|--------|
| visual_description | 分镜描述，最常编辑 | P0 |
| character_descriptions | 角色列表，tag 形式展示 | P1 |
| dialogue | 对话内容 | P1 |

### 视觉设计

- **编辑态**：textarea 带蓝色边框，底部显示「保存中...」或「已保存」
- **保存成功**：绿色 checkmark 闪现后消失
- **保存失败**：红色边框 + 错误提示

### 技术要点

- 使用 `contentEditable` 或受控 `textarea`
- debounce 保存请求（300ms）
- 乐观更新 + 失败回滚

## 功能二：拖拽重排序

### 目标

支持拖拽调整分镜顺序和跨章节移动。

### 支持的拖拽场景

1. **章节内排序** - 在同一章节内拖拽分镜调整顺序
2. **跨章节移动** - 将分镜拖到另一个章节中
3. **章节排序** - 拖拽整个章节调整章节顺序

### 交互细节

**拖拽手柄**：
- 分镜卡片左侧显示 6 点拖拽图标（⋮⋮），悬停时高亮
- 章节标题栏也有拖拽手柄

**拖拽过程**：
- 拖起时：原位置显示虚线占位框，被拖元素半透明跟随鼠标
- 拖拽中：目标位置显示蓝色插入线指示器
- 跨章节时：目标章节边框高亮，表示可放置

**放置反馈**：
- 放置成功：元素动画滑入新位置，后台静默保存
- 放置失败：元素弹回原位，Toast 提示错误原因

### 边界情况

- 生成中的分镜不可拖拽（显示锁定状态）
- 拖拽时自动展开目标章节

### 技术选型

使用 `@dnd-kit/core` 库：
- 轻量、性能好
- 支持键盘拖拽（无障碍）
- React 生态广泛使用

## 功能三：故事板概览 Tab

### 目标

新增「故事板」Tab，提供全局缩略图视图，一眼看到整个故事的视觉节奏。

### 视图布局

```
┌─────────────────────────────────────────────────────────────┐
│  [章节创作] [关联角色] [故事板] [排版导出]                      │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐    │
│  │ 第一章：初遇                                    [展开] │    │
│  │ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐   │    │
│  │ │ 01 │ │ 02 │ │ 03 │ │ 04 │ │ 05 │ │ 06 │ │ +  │   │    │
│  │ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘   │    │
│  └─────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ 第二章：冲突                                    [展开] │    │
│  │ ┌────┐ ┌────┐ ┌────┐ ┌────┐                         │    │
│  │ │ 01 │ │ 02 │ │ 03 │ │ +  │                         │    │
│  │ └────┘ └────┘ └────┘ └────┘                         │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 缩略图卡片

每个缩略图卡片（约 80x80px）显示：
- 分镜图像（已生成）或占位图标（未生成）
- 序号角标
- 状态指示器（生成中显示转圈、失败显示红点）

### 交互能力

| 操作 | 行为 |
|------|------|
| 单击 | 选中，底部显示分镜简要信息 |
| 双击 | 跳转到「章节创作」Tab 并定位到该分镜 |
| 拖拽 | 调整顺序（复用功能二的拖拽能力） |
| Shift+点击 | 多选（用于批量操作） |
| 右键 | 上下文菜单（重新生成、删除、移动到...） |

### 缩放控制

底部工具栏提供缩放滑块：
- 小图模式（60px）：一屏看更多
- 中图模式（100px）：默认
- 大图模式（160px）：看清细节

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 拖拽与现有点击事件冲突 | 使用拖拽手柄而非整卡片拖拽 |
| 大量分镜时性能问题 | 使用虚拟滚动（react-window） |
| 跨章节移动的数据一致性 | 后端事务保证原子性更新 |
| 移动端拖拽体验差 | 暂不支持移动端拖拽，保留原交互 |

---

## 成功指标

- Inline 编辑使用率 > 50%（对比对话框编辑）
- 拖拽排序使用率 > 30%
- 故事板 Tab 访问率 > 20%
- 用户反馈编辑效率提升
