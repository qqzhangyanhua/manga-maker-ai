## 🔧 故障排查

### 问题 1: 设置面板打不开

**症状:** 点击"设置"按钮无反应

**排查步骤:**

1. 检查浏览器控制台错误
   ```
   F12 → Console 标签
   查找红色错误信息
   ```

2. 检查组件是否正确导入
   ```bash
   grep -r "TimelineSettings" src/components/InfiniteCanvas/
   # 应该看到 TimelineSettings.tsx 和 index.ts
   ```

3. 重启开发服务器
   ```bash
   # Ctrl+C 停止
   pnpm dev
   ```

---

### 问题 2: 保存配置失败

**症状:** 点击保存后显示错误 Toast

**排查步骤:**

1. 检查网络请求
   ```
   F12 → Network 标签
   找到 PATCH /api/canvas/timeline/{id}
   查看 Response 状态码和内容
   ```

2. 检查后端日志
   ```bash
   # 查看终端输出
   # 应该看到: [INFO] 更新时间线配置
   ```

3. 检查数据库连接
   ```bash
   psql manga_maker -c "SELECT version();"
   ```

---

### 问题 3: 镜头生成很慢

**症状:** 生成时间 > 15秒

**排查步骤:**

1. 检查是否使用并行版本
   ```
   控制台应该显示: "开始并行生成镜头"
   而不是逐个片段的串行日志
   ```

2. 检查 novel-backend 是否运行
   ```bash
   curl http://localhost:8000/health
   # 应该返回: {"status": "healthy"}
   ```

3. 检查网络延迟
   ```
   F12 → Network 标签
   查看 /api/novel/canvas/plan-shots 请求耗时
   ```

---

### 问题 4: TypeScript 编译错误

**症状:** 保存文件后编译失败

**排查步骤:**

1. 运行类型检查
   ```bash
   npx tsc --noEmit
   ```

2. 查看具体错误
   ```bash
   # 应该输出具体的文件和行号
   # 根据提示修复类型错误
   ```

3. 清理缓存重试
   ```bash
   rm -rf .next
   pnpm dev
   ```
