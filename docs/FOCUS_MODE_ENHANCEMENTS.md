## ✨ 新增功能

### 1. 参考图选择功能

#### 功能描述
在右侧配置面板中新增"参考图片"选项，支持选择多张参考图来引导 AI 生成更符合预期的图片。

#### 使用方式

1. **打开参考图选择器**
   - 在右侧配置面板中找到"参考图片"折叠面板
   - 点击"选择参考图"按钮

2. **选择参考图来源**
   参考图选择器支持多个来源：
   - **本故事图片**：当前剧本已生成的分镜图片
   - **角色素材**：
     - 角色基础形象
     - 三视图（正面/侧面/背面）
     - 表情矩阵（开心/悲伤/愤怒等）
     - 服装变体
     - 姿势变体
   - **场景素材**：场景参考图（待实现）

3. **预览和管理**
   - 已选择的参考图会以缩略图形式显示
   - 鼠标悬停可以删除单个参考图
   - 显示已选择数量徽章

4. **生成图片**
   - 点击"生成图片"按钮
   - 系统会自动将参考图 URL 传递给 AI 模型
   - AI 会参考这些图片生成新的分镜图片

#### 技术实现

**数据结构**：
```typescript
interface ReferenceImage {
  id: string;
  url: string;
  source_type: "story" | "character_base" | "character_view" | "character_expression" | "character_outfit" | "character_pose";
  source_id?: string;
  label?: string;
}
```

**API 调用**：
```typescript
// 生成图片时自动附加参考图
{
  panel_id: "...",
  prompt: "...",
  reference_image_urls: ["url1", "url2", "url3"], // ← 新增参数
  model_name: "Nano-Banana-Pro",
  // ... 其他参数
}
```

**复用组件**：
- 完全复用现有的 `ReferenceImageSelector` 组件
- 无需新增 API 接口
- 与正常模式保持一致的用户体验

### 2. 章节展开/收起功能

#### 功能描述
左侧章节导航支持展开/收起切换，可以隐藏不需要查看的章节分镜，让界面更清爽。

#### 使用方式

1. **展开章节**
   - 点击章节标题
   - 箭头图标旋转 90°
   - 显示该章节下的所有分镜

2. **收起章节**
   - 再次点击章节标题
   - 箭头图标恢复
   - 隐藏该章节的分镜列表

3. **智能展开**
   - 默认展开当前分镜所在的章节
   - 选择其他章节的分镜时，自动展开该章节
   - 支持同时展开多个章节

#### 技术实现

**状态管理**：
```typescript
// 使用 Set 存储展开的章节 ID
const [expandedChapters, setExpandedChapters] = useState<Set<string>>(() => {
  // 默认展开当前分镜所在的章节
  if (state.currentPanel) {
    return new Set([state.currentPanel.chapter_id]);
  }
  return chapters.length > 0 ? new Set([chapters[0].id]) : new Set();
});
```

**切换逻辑**：
```typescript
const toggleChapter = useCallback((chapterId: string) => {
  setExpandedChapters((prev) => {
    const newSet = new Set(prev);
    if (newSet.has(chapterId)) {
      newSet.delete(chapterId); // 收起
    } else {
      newSet.add(chapterId);    // 展开
    }
    return newSet;
  });
}, []);
```

**自动展开**：
```typescript
const handlePanelSelect = useCallback((panel: Panel) => {
  actions.selectPanel(panel.id);
  // 确保该章节是展开的
  setExpandedChapters((prev) => {
    const newSet = new Set(prev);
    newSet.add(panel.chapter_id);
    return newSet;
  });
}, [actions]);
```

## 💡 使用建议

### 参考图使用技巧

1. **角色一致性**
   - 选择角色的基础形象作为参考
   - 如需特定表情，添加表情图
   - 如需特定服装，添加服装图

2. **场景参考**
   - 选择已生成的相似场景作为参考
   - 可以使用多张参考图增强效果

3. **风格控制**
   - 选择风格相似的图片作为参考
   - 参考图数量：建议 1-3 张

4. **组合使用**
   - 参考图 + 详细提示词 = 最佳效果
   - 参考图 + 角色选择 = 角色一致性
   - 参考图 + 高引导强度 = 更贴近参考

### 章节管理技巧

1. **专注创作**
   - 只展开当前正在编辑的章节
   - 其他章节收起，减少干扰

2. **快速导航**
   - 展开多个章节，快速切换分镜
   - 使用缩略图快速定位

3. **性能优化**
   - 如果分镜很多，收起不需要的章节
   - 减少渲染的元素数量
