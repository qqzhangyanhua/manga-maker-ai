## 🎨 特性亮点

### 1. 9种关系类型

| 类型 | 颜色 | 特效 | 用途 |
|------|------|------|------|
| 朋友 (friend) | 绿色 | 无 | 友好关系 |
| 敌人 (enemy) | 红色 | 动画 | 敌对关系 |
| 恋人 (lover) | 粉色 | 动画 | 爱情关系 |
| 亲人 (family) | 琥珀色 | 无 | 家庭关系 |
| 师父 (mentor) | 紫色 | 箭头 | 指导关系 |
| 徒弟 (student) | 靛蓝色 | 箭头 | 学习关系 |
| 对手 (rival) | 橙色 | 动画 | 竞争关系 |
| 盟友 (colleague) | 青色 | 无 | 合作关系 |
| 中立 (neutral) | 灰色 | 无 | 中立关系 |

### 2. 3种布局算法

**层次布局 (Dagre)**
- 自动排列节点层级
- 最小化边交叉
- 适合有明确上下关系的图谱

**圆形布局 (Circle)**
- 所有节点均匀分布在圆周上
- 直观展示整体关系
- 适合节点数量较少的场景

**网格布局 (Grid)**
- 节点按网格排列
- 整齐有序
- 适合需要精确控制位置的场景

## 📖 使用指南

### 1. 添加角色关系

在"角色管理"标签页,编辑角色时添加关系:

```typescript
{
  id: "char-1",
  name: "主角",
  role: "protagonist",
  relationships: [
    {
      characterId: "char-2",
      characterName: "导师",
      relation: "mentor",
      description: "传授武功的师父"
    },
    {
      characterId: "char-3",
      relation: "enemy",
      description: "杀父仇人"
    }
  ]
}
```

### 2. 查看关系图谱

1. 切换到"关系图谱"标签页
2. 系统自动生成可视化图谱
3. 使用布局按钮切换不同视图
4. 鼠标拖拽/滚轮缩放调整视图
5. 点击节点/边查看详情

### 3. 布局切换

- **层次布局**: 适合有明确上下级关系
- **圆形布局**: 适合展示整体关系网
- **网格布局**: 适合规整排列
