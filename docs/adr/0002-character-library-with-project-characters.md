# 角色保留为用户级角色库，项目通过项目角色引用

角色需要跨项目复用（同一个原创角色出现在多部作品中），同时项目内的剧本、分镜和图片生成只应该看到本项目的角色。我们决定让 `Character` 继续只属于用户（角色库），新增项目角色关联表，记录角色在该项目中的定位、人物弧光和顺序，用来替代 `StoryCharacter`。项目内引用角色的地方（分镜绑定、参考图选择、角色识别）都只能从项目角色中选。

## Considered Options

- **角色加必填的 project_id，跨项目时复制**：语义最简单，但会去掉角色库，并且复制后的参考图、服装和训练产物会分叉，难以同步。
