## 📊 设计问题诊断总结

### 当前主要问题：

1. **配色过暗** ❌
   - 背景 `#09090b` 接近纯黑，长时间观看疲劳
   - 单一 zinc 色系缺乏层次
   - orange-500 强调色对比过强

2. **排版层级不足** ❌
   - 字体大小单调（只有 text-3xl）
   - 粗细对比不够（只有 font-bold）
   - 行高未优化

3. **留白不均衡** ❌
   - 整体过于紧凑（py-8 px-4）
   - 卡片内部留白缺乏节奏
   - 缺乏"呼吸感"

4. **视觉层级薄弱** ❌
   - 卡片与背景区分度低
   - hover 状态变化微妙
   - 空状态设计简陋

### 改进后效果：

✅ **配色**：引入渐变 + 降低饱和度 + 提高对比度
✅ **排版**：增大字号 + 丰富粗细 + 优化行高
✅ **留白**：加大 padding + 统一间距 + 增加呼吸感
✅ **视觉层级**：阴影/模糊/渐变 + 明显 hover + 优化空状态

## ❓ 常见问题

### Q: 需要额外依赖吗？
**A:** 不需要，所有方案都使用标准 TailwindCSS。

### Q: 会影响性能吗？
**A:**
- Vercel: backdrop-blur 有中等影响
- Linear: 多层渐变有较高影响
- Apple: 几乎无影响（推荐）

### Q: 如何回滚？
**A:** 所有脚本都会自动备份，查找 `page.tsx.backup.*` 文件恢复。

### Q: 如何修改颜色？
**A:** 直接搜索替换 TailwindCSS 类名，例如：
```tsx
// 将橙色改为红色
orange-500 → red-500
```
