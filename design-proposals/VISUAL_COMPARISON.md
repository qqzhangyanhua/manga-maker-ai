## 按钮样式对比

### Vercel 风格
```css
/* 主按钮 */
bg-gradient-to-r from-orange-500 to-orange-400
hover:from-orange-400 hover:to-orange-300
shadow-lg shadow-orange-500/25
hover:shadow-xl hover:shadow-orange-500/40

/* 次要按钮 */
border-zinc-700 text-zinc-100
hover:bg-zinc-800 hover:text-white
```

### Linear 风格
```css
/* 主按钮 */
bg-gradient-to-r from-purple-600 via-purple-500 to-blue-500
hover:from-purple-500 hover:via-purple-400 hover:to-blue-400
shadow-lg shadow-purple-500/30
hover:shadow-xl hover:shadow-purple-500/50
rounded-xl

/* 次要按钮 */
border-purple-500/30 text-purple-200
hover:bg-purple-500/20 hover:text-white
rounded-xl
```

### Apple 风格
```css
/* 主按钮 */
bg-blue-500
hover:bg-blue-600
shadow-sm hover:shadow-md
rounded-xl

/* 次要按钮 */
border-gray-200 text-gray-700
hover:bg-gray-50 hover:text-gray-900
rounded-xl
```

## 技术实现差异

| 特性 | Vercel | Linear | Apple |
|------|--------|--------|-------|

## 响应式设计对比

所有三个方案都使用相同的响应式断点：

```tsx
// 卡片网格
grid-cols-1           // 手机: 1 列
md:grid-cols-2        // 平板: 2 列
lg:grid-cols-3        // 桌面: 3 列

// 容器宽度
max-w-7xl mx-auto     // 所有方案统一
```

但留白在不同屏幕尺寸下的差异：

| 方案 | 手机 | 平板 | 桌面 |
|------|------|------|------|
| Vercel | `px-4 py-8` | `px-6 py-12` | `px-6 py-12` |
| Linear | `px-6 py-12` | `px-8 py-16` | `px-8 py-16` |
| Apple | `px-8 py-16` | `px-12 py-20` | `px-12 py-20` |

## 总结

### 如果你想要...

**技术感 + 专业感** → 选择 **Vercel 风格**
- 深色主题护眼
- 玻璃态模糊高级感
- 橙色渐变科技感

**创意感 + 视觉冲击** → 选择 **Linear 风格**
- 紫蓝渐变梦幻感
- 多层光晕氛围感
- 大胆用色辨识度高

**简洁感 + 高端质感** → 选择 **Apple 风格**
- 极简设计认知负担低
- 纯白背景专业感
- 微妙细节高端感
