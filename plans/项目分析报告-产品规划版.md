## 一、项目概述

### 1.1 核心定位
ComicAI 是一个 **AI 驱动的漫画创作平台**，旨在降低漫画创作门槛，让用户通过简单的文字描述或照片上传，快速生成分镜漫画。

### 1.2 目标用户
- **创作者**: 漫画作者、插画师、故事创作者
- **爱好者**: 动漫爱好者、Cosplayer、内容创作者
- **企业**: 品牌营销、教育培训、内容生产团队

### 1.3 核心价值
- **降低门槛**: 无需绘画技能，通过 AI 生成专业级漫画
- **提升效率**: 从创意到成品，缩短创作周期
- **角色一致性**: "数字演员"系统，保证角色在多场景下的视觉统一

## 五、角色一致性方案深度分析

### 5.1 当前方案: 三视图 + Prompt 锚定
**实现逻辑**:
1. 用户上传角色照片
2. AI 生成三视图 (正面/侧面/背面)
3. 生成时组合:
   ```
   [参考图] + [详细文字描述] + [当前动作] + [风格限定]
   ```

**优点**:
- ✅ 无需模型训练，快速部署
- ✅ Gemini 多模态理解能力强

**缺点**:
- ❌ 复杂姿态/角度下一致性不稳定
- ❌ 无法精细控制 (如"改变刘海方向")
- ❌ 依赖 API 稳定性

---

### 5.2 优化方案: LoRA 微调 (建议实施)
**技术路线**:
```
用户上传 10-20 张角色图 → 自动训练 LoRA 模型 → 生成时加载 LoRA
```

**实施步骤**:
1. **数据准备**:
   - 用户提供多角度照片
   - 自动打标签 (BLIP/WD14 Tagger)
   - 生成训练数据集

2. **模型训练**:
   - 使用 Kohya LoRA Training Script
   - 训练参数: 500-1000 steps, lr=1e-4
   - 输出 LoRA 权重文件 (.safetensors)

3. **部署使用**:
   - 上传到 MinIO
   - 生成时通过 `lora:<trigger_word>:1.0` 激活

4. **成本估算**:
   - 训练耗时: 5-15分钟 (RTX 3090)
   - 存储: ~50MB/角色
   - 云端 GPU: $0.50-2.00/次

**数据模型**:
```prisma
Character {
  lora_model_url: "minio://bucket/user123/char456.safetensors"
  lora_trigger_word: "sks_person"
  training_status: "ready"
}
```

---

### 5.3 混合方案: 三视图 + LoRA (推荐)
**最佳实践**:
- **免费用户**: 三视图 + Prompt (快速体验)
- **付费用户**: LoRA 训练 (专业级一致性)

**产品设计**:
```
[角色库] → [快速生成] (三视图模式)
         ↘ [训练专属模型] ($2.99/角色) → [极致一致性]
```

**好处**:
- 降低 50% 成本
- 减少无效重试
- 提升用户控制感

  ```
  [negative: extra fingers, blurry]"
  ```

**技术实现**:
- LLM Prompt 模板: [`prompt-builder.ts`](../src/lib/prompt-builder.ts)

### 6.3 Gemini 安全过滤规避技巧
**问题**: 漫画常见的打斗、武器、血液易触发 Safety Block

**解决方案**:
```javascript
// Prompt 软化字典
const softWords = {
  "blood": "red paint",
  "kill": "defeat",
  "knife": "tool",
  "gun": "device",
  "wound": "mark"
};

function sanitizePrompt(prompt: string) {
  return Object.entries(softWords).reduce(
    (text, [bad, good]) => text.replace(new RegExp(bad, 'gi'), good),
    prompt
  );
}
```

### 8.2 安全风险
- ❗ **API Key 泄露**: `.env` 文件可能被提交到 Git
- ❗ **CORS 配置**: 需要严格限制域名
- ❗ **用户上传**: 需要文件类型/大小校验
- ❗ **SQL 注入**: Prisma 已提供防护，但需审计原始查询

**建议**:
- 使用 `dotenv-vault` 加密环境变量
- 添加 Rate Limiting (每用户 10req/min)
- 文件上传: 病毒扫描 + 格式白名单

---

### 8.3 性能瓶颈
| 问题 | 影响 | 解决方案 |
