# 19 AI 赋能开发的四大核心

**模式：角色反转（AI POV）**

- **场景**：核心 1 & 2 展示
- **画面布局**：左右两个核心并列

### 核心 1 - MCP 协议（左侧，占 50%）：
- **图标**：🔍 智能上下文获取
- **Claude 介绍姿态**：指向左侧展示区
- **展示内容**：
  - **MCP 工具拟人化团队**（三个成员）：
    - Auggie（代码检索）：戴侦探帽
    - Context7（文档查询）：拿着书
    - Sequential Thinking（推理）：托腮思考
  - **价值数据**（大字显示）：
    ```
    秒级定位
    200x-240x 效率提升

    Auggie:  3秒 vs 10分钟 (200x)
    Context7: 5秒 vs 20分钟 (240x)
    ```
  - **核心价值标签**：
    - ✓ 标准化接口（一次配置，多模型复用）
    - ✓ 安全隔离（权限控制 + 审计）
    - ✓ 实时上下文（动态获取，按需加载）
- **对话气泡（Claude）**："MCP 协议让我能主动获取上下文，秒级定位！"

### 核心 2 - Skill 系统（右侧，占 50%）：
- **图标**：⚙️ 专业化工作流自动化
- **Claude 介绍姿态**：指向右侧展示区
- **展示内容**：
  - **Skill 拟人化团队**（四个成员）：
    - /commit（Git 专家）：拿着提交记录
    - /review（审查官）：拿着放大镜
    - /code（代码师）：拿着键盘
    - /ccg:dev（工作流大师）：拿着流程图
  - **工作流可视化**：
    ```
    用户需求
       ↓
    Skill 自动编排
       ↓
    /code → /review → /commit
       ↓
    高质量代码
    ```
  - **核心价值标签**：
    - ✓ 专业化分工（每个 Skill 专注一件事）
    - ✓ 可组合性（自动编排完整工作流）
    - ✓ 减少重复（封装最佳实践）
- **对话气泡（Claude）**："Skill 系统让复杂工作流自动化，一键执行！"

## 第三格（完整横格）：
- **场景**：核心 3 & 4 展示
- **画面布局**：左右两个核心并列

### 核心 3 - 多模型协作（左侧，占 50%）：
- **图标**：🤝 各取所长，交叉验证
- **Claude 介绍姿态**：站在中间，像乐队指挥
- **展示内容**：
  - **三个 AI 模型协作**：
    - **Claude**（中间）：主控协调，穿指挥服
    - **Codex**（左）：后端逻辑，戴眼镜
    - **Gemini**（右）：UI/UX，拿调色板
  - **协作流程可视化**：
    ```
    需求：添加拖拽功能
         ↓
    Codex: 拖拽算法 (2分钟)
    Gemini: UI动画 (2分钟)
         ↓
    Claude: 整合重构 (15分钟)
         ↓
    Codex+Gemini: 交叉审查 (5分钟)
         ↓
    30分钟完成 2天工作 (96x)
    ```
  - **核心价值标签**：
    - ✓ 精准分工（各取所长）
    - ✓ 并行处理（提升效率）
    - ✓ 交叉验证（保障质量）
- **对话气泡（Claude）**："我协调 Codex 和 Gemini，各取所长，交叉验证！"

### 核心 4 - 零写入安全（右侧，占 50%）：
- **图标**：🔒 代码主权，安全可控
- **Claude 介绍姿态**：手持"主控钥匙"🔑
- **展示内容**：
  - **安全架构金字塔**：
    ```
    顶层：Claude (主控)
    ✅ 读取 ✅ 写入 ✅ 执行

    中层：Codex/Gemini (协作)
    ✅ 读取 ❌ 写入 ❌ 执行

    底层：文件系统 (保护)
    🔒 外部模型无法直接访问
    ```
  - **安全流程可视化**：
    ```
    外部模型生成 Diff (只读)
         ↓
    Claude 思维沙箱模拟
         ↓
    Claude 检查 + 重构
         ↓
    Claude 最终实施 (写入)
    ```
  - **核心价值标签**：
    - ✓ 零写入权限（外部模型无法改文件）
    - ✓ Claude 主权（最终决策和实施）
    - ✓ 质量保障（所有建议必须审查）
- **对话气泡（Claude）**："外部模型只生成建议，我主控实施，代码主权安全可控！"
