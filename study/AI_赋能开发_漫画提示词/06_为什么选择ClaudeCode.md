# 06 为什么选择 Claude Code

**模式：角色反转（AI POV）**

四格漫画竖版布局，标题在漫画顶部居中，风格简洁、清晰易懂，采用 AI 第一人称视角，所有元素均以卡通风格表现，适合用于网络传播。

---

## 标题（居中）：
**《Claude Code 的自我介绍》**（中文，加粗）

---

## 第一格（完整横格）：
- **场景**：Claude AI 的拟人化形象（可爱的机器人/助手形象）站在舞台中央
- **Claude 形象**：
  - 卡通化的 AI 机器人，友好的表情
  - 穿着印有"Claude Code"字样的T恤
  - 右手比出"第一"的手势
- **对话气泡（Claude）**："大家好！我是 Claude Code，让我介绍我的优势～"
- **背景**：简洁的舞台，聚光灯打在 Claude 身上
- **底部标注**："优势 1：MCP 生态系统"

---

## 第二格（完整横格）：
- **场景**：Claude 展示 MCP 生态系统
- **画面布局**：
  - **Claude** 站在中心，手指向周围的 MCP 工具
  - **周围环绕的 MCP 工具图标**（拟人化形象）：
    - Auggie（代码检索专家，戴侦探帽）
    - Context7（文档博士，戴学士帽，拿着书）
    - Sequential Thinking（思考者，托腮沉思）
    - Filesystem（文件管家，抱着文件夹）
  - 所有工具用虚线连接到 Claude（表示可复用）
- **对话气泡（Claude）**："我有完整的 MCP 生态，标准协议，工具可复用！"
- **特效**：工具图标周围有发光特效 ✨
- **底部标注**："优势 2：Skill 系统"

---

## 第三格（完整横格）：
- **场景**：Claude 展示 Skill 系统和多模型协作
- **画面布局**：
  - **Claude** 站在指挥台上（像乐队指挥）
  - **左侧**：Skill 系统图标
    - /commit（Git 专家，拿着 Git 标志）
    - /review（代码审查官，拿着放大镜）
    - /ccg:dev（工作流大师，拿着流程图）
  - **右侧**：其他 AI 模型作为"子 Agent"
    - Codex（算法专家，戴眼镜）
    - Gemini（设计师，拿着调色板）
  - 所有角色用箭头指向 Claude（表示 Claude 主控）
- **对话气泡（Claude）**："我可以调用 Codex/Gemini 作为子 Agent，封装专业工作流！"
- **特效**：音乐符号飘舞，表示协调有序
- **底部标注**："优势 3：多模型协作"

---

## 第四格（完整横格）：
- **场景**：Claude 展示核心优势
- **画面布局**：
  - **Claude** 站在中心，表情自信，双臂交叉
  - **周围四个优势图标**（用盾牌形状）：
    - 🛡️ **代码主权**："我主控，外部模型零写入"
    - 📚 **长上下文**："200K Token，大型项目友好"
    - 🎯 **精准协作**："各取所长，交叉验证"
    - 🔒 **安全可控**："Unified Diff Patch，严格审查"
- **对话气泡（Claude）**："而且我主控，外部模型零写入，代码主权安全可控！🎉"
- **背景**：发光的光环效果，突出专业感
- **底部大字总结**（加粗）：
  **"Claude Code = MCP + Skill + 多模型协作 + 代码主权"**

---

## 附加风格要求：
- Claude 的拟人化形象要友好可爱，不能太机械
- 四格要体现"层层递进"：生态 → 系统 → 协作 → 主权
- MCP 工具和其他 AI 模型的拟人化要有个性：用服装、道具区分
- 第四格的四个优势要用图标 + 文字，清晰醒目
- 整体风格：专业但不失趣味，突出 Claude Code 的核心竞争力
- 特效使用：✨ 发光、🎵 音符、🛡️ 盾牌，增加视觉吸引力
