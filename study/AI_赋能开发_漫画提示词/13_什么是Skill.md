# 13 什么是 Skill？

**模式：角色反转（AI POV）**

四格漫画竖版布局，标题在漫画顶部居中，风格简洁、清晰易懂，采用 Claude AI 第一人称视角介绍 Skill 系统，所有元素均以卡通风格表现，适合用于网络传播。

---

## 标题（居中）：
**《Claude 的 Skill 系统介绍》**（中文，加粗）

---

## 第一格（完整横格）：
- **场景**：Claude AI 站在讲台上，像讲师一样介绍 Skill 系统
- **Claude 形象**：
  - 卡通化的 AI 机器人，友好专业的表情
  - 穿着印有"Skill Expert"字样的马甲
  - 右手指向身后的大屏幕
- **大屏幕显示**：
  ```
  Skill = Prompt Template + Tool Access + Workflow Logic
  ```
- **对话气泡（Claude）**："大家好！让我介绍我的 Skill 系统～"
- **背景**：教室/讲座场景，台下坐着小明、小红、小刚
- **底部标注**："什么是 Skill？"

---

## 第二格（完整横格）：
- **场景**：Claude 展示专业化分工
- **画面布局**：四个 Skill 拟人化形象（像团队成员）

### /commit Skill（左上）：
- **形象**：Git 专家，戴棒球帽，穿印有 Git 标志的T恤
- **手里拿着**：笔记本（记录代码改动）
- **对话气泡**："我负责分析改动 + 生成 Commit Message！"
- **标签**："Git 提交专家"

### /review Skill（右上）：
- **形象**：代码审查官，戴眼镜，拿着放大镜
- **手里拿着**：检查清单（checklist）
- **对话气泡**："我负责多角度审查 + 提出改进建议！"
- **标签**："代码审查专家"

### /debug Skill（左下）：
- **形象**：调试侦探，戴侦探帽，拿着手电筒
- **手里拿着**：错误日志
- **对话气泡**："我负责问题诊断 + 修复方案！"
- **标签**："调试专家"

### /code Skill（右下）：
- **形象**：代码生成师，穿程序员格子衫，拿着键盘
- **手里拿着**：代码文件
- **对话气泡**："我负责原型生成 + 最佳实践！"
- **标签**："代码生成专家"

### 中间 - Claude 的位置：
- **Claude 站在中间**，像乐队指挥一样
- **对话气泡（Claude）**："每个 Skill 都是专业化的 AI 工作流！"
- **箭头**：从 Claude 指向四个 Skill（表示协调关系）

---

## 第三格（完整横格）：
- **场景**：Skill 的可组合性展示
- **画面布局**：工作流示意图

### 用户需求（顶部）：
- **输入框**："实现新功能并提交"
- **箭头指向下方**

### Orchestrator（中间）- Claude：
- **Claude 形象**：主控者，手持指挥棒
- **思考气泡**：
  ```
  1. 先用 /code 生成代码
  2. 再用 /review 审查
  3. 最后用 /commit 提交
  ```
- **三个箭头**：依次指向三个 Skill

### 自动化工作流（底部）：
- **流程图**（用箭头连接）：
  ```
  /code Skill → /review Skill → /commit Skill
     ↓              ↓               ↓
  生成代码       审查代码        提交代码
  ```
- **时间标注**：总共 5 分钟（自动化）
- **对比标注**：手动需要 2 小时

### Claude 的说明气泡：
- **对话气泡（Claude）**："Skill 可以组合！我自动编排完整工作流～"

---

## 第四格（完整横格）：
- **场景**：Skill vs 直接调用 AI 的对比
- **画面布局**：左右分屏

### 左半边 - 直接调用 AI（灰色调）：
- **场景**：小刚直接问 AI
- **画面**：
  - 小刚在对话框输入："帮我写代码"
  - AI 回复：生成了代码（但缺少审查、测试等步骤）
  - 小刚表情：困惑
- **问题标注**（红色）：
  - ❌ 需要详细指令（每次都要说）
  - ❌ 容易遗漏步骤（忘记测试、审查）
  - ❌ 缺乏标准化（每次结果不一致）
- **标注**："简单提问 → 简单答案"

### 右半边 - Skill 封装（蓝色科技调）：
- **场景**：小红使用 Skill
- **画面**：
  - 小红输入简单命令：`/code "用户认证功能"`
  - Skill 自动执行：
    ```
    ✓ 生成代码
    ✓ 编写测试
    ✓ 添加文档
    ✓ 遵循最佳实践
    ✓ 类型安全检查
    ```
  - 小红表情：满意、轻松
- **优势标注**（绿色）：
  - ✓ 自动最佳实践（无需每次指定）
  - ✓ 强制完整性（不会遗漏步骤）
  - ✓ 标准化输出（质量一致）
- **标注**："复杂工作流 → 一键执行"

### 底部总结区域：
- **大字标题**（加粗）：
  **"简单任务直接对话，复杂工作流用 Skill"**
- **原则说明**（用图标强调）：
  - 💬 **简单提问** → 直接对话（快速灵活）
  - ⚙️ **代码生成** → Skill 封装（自动最佳实践）
  - 🔁 **重复工作流** → Skill 自动化（减少重复）
  - 🎯 **多步骤任务** → Skill 编排（确保完整性）

---

## 附加风格要求：
- Claude 的拟人化形象要专业友好，像专家导师
- 四个 Skill 的拟人化要有明显个性：服装、道具、表情各异
- 第二格的团队感要强：用箭头和站位表示协调关系
- 第三格的工作流图要清晰：用不同颜色区分各阶段
- 第四格左右对比要强烈：灰色混乱 vs 蓝色整洁
- 整体风格：教育性 + 趣味性，像科普讲座
- 特效使用：✨ 强调重点，📋 流程图，🎯 核心概念
