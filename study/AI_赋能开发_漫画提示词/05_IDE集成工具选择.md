# 05 IDE 集成工具选择

**模式：场景对比（Split Screen）**

四格漫画竖版布局，标题在漫画顶部居中，风格简洁、幽默、清晰易懂，所有人物均以卡通风格表现，适合用于网络传播。

---

## 标题（居中）：
**《AI Coding：工具选择决定效率》**（中文，加粗）

---

## 第一格（完整横格）：
- **场景**：标题栏，提问
- **文字**："需要完整 IDE 体验吗？"
- **背景**：简洁的分割线，左右两侧用不同色调区分（左侧亮色调，右侧灰暗色调）
- **副标题**：
  - 左侧："YES → Cursor (主流)"
  - 右侧："NO → 记事本？？？"

---

## 第二格（完整横格，左右分屏）：

### 左半边 - Cursor 用户（小红，亮色调）：
- **场景**：现代化办公桌，小红坐在电脑前
- **屏幕显示**：
  - Cursor IDE 界面，代码整齐排列
  - AI Agent 模式提示："正在生成代码..."
  - 侧边栏显示 MCP 工具
- **小红表情**：开心、轻松工作
- **桌面元素**：
  - 一杯咖啡
  - 整洁的键盘和鼠标
  - 绿植装饰
- **标注**："Agent 模式 + MCP 集成"

### 右半边 - 记事本用户（小刚，灰暗色调）：
- **场景**：凌乱的办公桌，小刚坐在电脑前
- **屏幕显示**：
  - Windows 记事本，代码没有高亮
  - 多个浏览器标签打开（ChatGPT 网页版）
  - 手动复制粘贴代码
- **小刚表情**：痛苦、抓头发
- **桌面元素**：
  - 凌乱的便签纸（贴满屏幕边缘）
  - 多个空咖啡杯
  - 散落的零食袋
- **标注**："手动复制粘贴"

---

## 第三格（完整横格，左右分屏）：

### 左半边 - 小红的工作进度（亮色调）：
- **场景**：时间线展示
- **时间标注**：30 分钟后
- **画面**：
  - 小红站起来伸懒腰，表情满意
  - 电脑屏幕显示："功能开发完成 ✓"
  - 代码行数：200 行（高质量）
  - 测试覆盖率：95%
- **对话气泡**："搞定！可以下班了～"
- **背景元素**：窗外阳光明媚

### 右半边 - 小刚的工作进度（灰暗色调）：
- **场景**：时间线展示
- **时间标注**：2 天后
- **画面**：
  - 小刚依然在电脑前，表情憔悴
  - 电脑屏幕显示："功能开发 50%..."
  - 多个报错窗口弹出
  - 凌乱的代码（没有格式化）
- **对话气泡**："怎么还没搞定？！"
- **背景元素**：窗外已是深夜，月亮高挂

---

## 第四格（完整横格）：
- **场景**：对比总结
- **布局**：中间一个大箭头，左右两侧对比
- **左侧 - 小红数据**（绿色高亮）：
  - ⚡ 开发时间：30 分钟
  - ✓ 代码质量：高
  - ✓ 测试覆盖：95%
  - 😊 心情：愉悦
- **右侧 - 小刚数据**（红色警告）：
  - ⏳ 开发时间：2 天（未完成）
  - ❌ 代码质量：低
  - ❌ 测试覆盖：0%
  - 😭 心情：崩溃
- **中间大字总结**（加粗）：
  **"工具选型决定效率"**
- **底部提示**：
  ```
  推荐：Cursor ($20/月) / GitHub Copilot ($10/月) / Windsurf ($15/月)
  ```

---

## 附加风格要求：
- 左右对比要有明显的色调差异：小红（亮色 + 整洁），小刚（灰暗 + 凌乱）
- 时间对比要醒目：30 分钟 vs 2 天（用大字号 + 时钟图标）
- 小刚的桌面要夸张凌乱：便签纸、空咖啡杯、零食袋堆满
- 第四格的对比数据要清晰：用表格 + 颜色区分（绿色 vs 红色）
- 整体风格：幽默但真实，突出工具选择的重要性
