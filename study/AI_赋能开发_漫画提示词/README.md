## 使用建议

1. **保持一致性**：同一系列漫画使用相同的人物形象和色调
2. **模式轮换**：不同主题使用不同叙事模式，增加新鲜感
3. **视觉重点**：每张漫画都有独特的视觉彩蛋
4. **对比鲜明**：正确/错误做法用不同色调区分（明亮 vs 灰暗）
5. **数据醒目**：效率提升数据用大字号 + 颜色高亮
