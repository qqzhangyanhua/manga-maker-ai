# 07 什么是 MCP？

**模式：场景对比（Split Screen）**

四格漫画竖版布局，标题在漫画顶部居中，风格简洁、幽默、清晰易懂，所有人物均以卡通风格表现，适合用于网络传播。

---

## 标题（居中）：
**《MCP：让 AI 从"被动回答"到"主动获取上下文"》**（中文，加粗）

---

## 第一格（完整横格）：
- **场景**：标题栏，定义展示
- **文字**："传统方式 vs MCP 方式"
- **背景**：简洁的分割线，左右两侧用不同色调区分（左侧灰暗色调，右侧科技蓝色调）
- **副标题**：
  - 左侧："手动复制粘贴"
  - 右侧："标准协议自动化"

---

## 第二格（完整横格，左右分屏）：

### 左半边 - 传统方式（灰暗色调）：
- **场景**：小刚在电脑前手动复制粘贴
- **画面细节**：
  - 小刚左手按着代码文件，右手拖动鼠标选择代码
  - 屏幕分成两个窗口：
    - 左窗口：VS Code（代码编辑器）
    - 右窗口：ChatGPT 网页版
  - 小刚表情：疲惫、机械重复
- **动作流程**（用箭头和标注展示）：
  1. 复制代码（Ctrl+C）
  2. 切换窗口
  3. 粘贴到 AI（Ctrl+V）
  4. 等待回答
- **时间标注**：10 分钟
- **标注文字**："手动 → 容易漏信息 → 上下文丢失"

### 右半边 - MCP 方式（科技蓝色调）：
- **场景**：小红在 Claude Code 中自然对话
- **画面细节**：
  - 小红轻松坐在椅子上，单手操作
  - 屏幕显示：Claude Code 终端界面
  - 用户输入："找到所有认证相关的代码"
  - MCP 自动工作：
    - Auggie MCP 图标闪烁（正在检索）
    - 代码库结构图可视化
    - 精准结果自动返回
  - 小红表情：轻松、满意
- **动作流程**（用箭头和标注展示）：
  1. 自然语言提问
  2. MCP 自动获取上下文
  3. 实时、精准返回结果
- **时间标注**：3 秒
- **标注文字**："自动化 → 实时 → 安全"

---

## 第三格（完整横格，左右分屏）：

### 左半边 - 传统方式的问题（灰暗色调）：
- **场景**：小刚复制错了内容
- **画面细节**：
  - 小刚发现复制的代码不完整（漏了几行）
  - AI 给出错误答案（屏幕显示红色错误提示）
  - 小刚表情：崩溃、抓头发
- **对话气泡**："糟了！忘记复制那个函数了..."
- **问题标注**（红色）：
  - ❌ 上下文不完整
  - ❌ AI 理解错误
  - ❌ 需要重新复制

### 右半边 - MCP 方式的优势（科技蓝色调）：
- **场景**：小红得到完美答案
- **画面细节**：
  - MCP 自动获取了完整上下文
  - 屏幕显示：精准的代码定位 + 相关文件列表
  - Claude 给出准确建议
  - 小红表情：满意、竖起大拇指
- **对话气泡**："完美！所有相关代码都找到了～"
- **优势标注**（绿色）：
  - ✓ 自动获取完整上下文
  - ✓ AI 理解准确
  - ✓ 零人工干预

---

## 第四格（完整横格）：
- **场景**：MCP 核心价值总结
- **布局**：三个核心价值模块（用卡片形式）
- **左侧卡片 - 标准化接口**：
  - 图标：USB 插头（表示即插即用）
  - 标题："标准化接口"
  - 说明：
    - 一次配置，多模型复用
    - 无需为每个工具写专用代码
    - 类似 USB 协议的即插即用
- **中间卡片 - 安全隔离**：
  - 图标：盾牌 + 锁
  - 标题："安全隔离"
  - 说明：
    - 工具与模型之间的权限控制
    - 防止模型直接访问文件系统
    - 审计与日志追踪
- **右侧卡片 - 实时上下文**：
  - 图标：闪电 + 数据库
  - 标题："实时上下文"
  - 说明：
    - 动态获取最新代码库信息
    - 按需加载，节省 Token
    - 支持海量代码库（> 100 万行）
- **底部大字总结**（加粗）：
  **"MCP = Model Context Protocol（模型上下文协议）"**
- **副标题**："让 AI 从'被动回答'到'主动获取上下文'"

---

## 附加风格要求：
- 左右对比要有明显的色调差异：传统方式（灰暗 + 混乱），MCP 方式（蓝色科技感 + 整洁）
- 时间对比要醒目：10 分钟 vs 3 秒（用大字号 + 时钟图标）
- 第二格的"动作流程"要用箭头和数字清晰标注
- 第三格的问题/优势要用颜色区分（红色 ❌ vs 绿色 ✓）
- 第四格的三个卡片要整齐排列，图标要醒目
- 整体风格：科技感 + 易懂，突出 MCP 的革命性
