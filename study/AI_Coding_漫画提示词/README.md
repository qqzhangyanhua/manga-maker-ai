## 人物设定

### 主要角色

| 角色 | 描述 | 定位 |
|------|------|------|
| **技术总监/安全主管** | 分头发型、休闲西装、表情认真 | 权威/问责者 |
| **小明** | 蓝色格子衬衫、戴眼镜、程序员气质 | 正确示范（后端） |
| **小红** | 休闲时尚穿搭、马尾辫 | 正确示范（前端） |
| **小刚** | 戴圆眼镜、帽衫、略显懒散 | 反面教材（全栈） |
| **AI 机器人** | 可爱卡通形象、有表情变化 | 拟人化 AI |

### 小刚的命运

小刚在不同漫画中的结局：
- 被扔出窗外（01, 06, 09, 10, 14）
- 陷入死循环（02）
- 效率极低（03, 07）
- 项目延期（05）
- 面试失败（11）
- 维护噩梦（13）
- 上下文崩溃（15）

## 使用建议

1. **保持一致性**：同一系列漫画使用相同的人物形象
2. **模式轮换**：不同主题使用不同叙事模式，增加新鲜感
3. **视觉重点**：每张漫画都有独特的视觉彩蛋
4. **对比鲜明**：正确/错误做法用不同色调区分
