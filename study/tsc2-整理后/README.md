## 使用建议

### 替身文作者
按"宏观→中观→微观→进阶"的顺序学习,重点关注人物关系和情感张力。

### 系统文作者
- 轻松向: 使用"多子多福"工具链
- 黑暗向: 使用"黑暗多子多福"完整体系

### 情感描写提升
"欲念描写专家"提供五感描写和情绪渲染的专业技法。

### 题材混合
四个题材可以交叉使用,例如在替身文中借鉴欲念描写技法。

## 与tsc的区别

- **tsc**: 通用流程 + 6大题材(世情、玄幻、四合院、狗血女文、知乎短篇、规则怪谈)
- **tsc2**: 成人向题材专精(替身文、多子多福、黑暗多子多福、欲念描写)

两个库互补使用,可覆盖从全年龄到成人向的完整创作需求。
