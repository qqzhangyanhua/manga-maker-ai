# 参考图生成优化说明

## 问题分析

之前的实现只是把参考图的 URL 作为文本放在提示词中，例如：
```
reference image: http://xxx/base.png, copy this exact style and character
```

但是 Gemini 等图片生成模型需要真正接收图片内容（base64格式），才能"看到"参考图。

## 解决方案

### 1. 新增参数支持

在 `ImageGenerationParams` 接口中新增 `referenceImageUrl` 参数：

```typescript
export interface ImageGenerationParams {
  // ... 其他参数
  referenceImageUrl?: string; // 参考图URL，将被转换为base64并发送给模型
}
```

### 2. 实现 URL 转 Base64 工具函数

新增 `urlToBase64` 函数，用于下载参考图并转换为 base64 格式：

```typescript
async function urlToBase64(imageUrl: string): Promise<string> {
  // 1. 下载图片
  const response = await fetch(imageUrl);
  const arrayBuffer = await response.arrayBuffer();
  const buffer = Buffer.from(arrayBuffer);
  
  // 2. 转换为 base64
  const base64 = buffer.toString('base64');
  
  // 3. 添加 data URL 前缀
  const contentType = response.headers.get('content-type') || 'image/png';
  return `data:${contentType};base64,${base64}`;
}
```

### 3. 修改 OpenAI/Gemini API 调用

在 `callOpenAIImageAPI` 函数中：

**之前的实现：**
```typescript
messages: [
  {
    role: "user",
    content: [
      {
        type: "text",
        text: prompt, // 只有文本提示词
      },
    ],
  },
]
```

**优化后的实现：**
```typescript
// 1. 如果有参考图，先下载并转换为 base64
let referenceImageBase64: string | undefined;
if (referenceImageUrl) {
  referenceImageBase64 = await urlToBase64(referenceImageUrl);
}

// 2. 构建 content 数组
const contentArray = [];

// 先放参考图
if (referenceImageBase64) {
  contentArray.push({
    type: "image_url",
    image_url: {
      url: referenceImageBase64, // data:image/png;base64,iVBORw0KG...
    },
  });
}

// 再放文本提示词
contentArray.push({
  type: "text",
  text: prompt,
});

// 3. 发送请求
messages: [
  {
    role: "user",
    content: contentArray, // 包含图片和文本
  },
]
```

### 4. 优化提示词策略

有参考图时，提示词更加强调"严格遵循参考图"：

```typescript
fullPrompt = [
  `IMPORTANT: You must draw the EXACT SAME character shown in the reference image.`,
  `Keep everything identical: face, body type, proportions, art style, colors.`,
  `Only change: outfit to ${outfitPrompt}.`,
  `Full body view, standing pose, simple white background.`,
  `Do NOT change the character's appearance, style, or proportions.`
].join(" ");
```

### 5. 更新调用流程

在 `generateOutfit` 函数中传递 `referenceImageUrl`：

```typescript
const result = await callImageGenerationByType({
  providerType,
  prompt: fullPrompt,
  negative_prompt: negativePrompt,
  width: 512,
  height: 768,
  steps: 25,
  cfg_scale: 7.5,
  referenceImageUrl, // 传递参考图URL
});
```

## 关键改进点

1. ✅ **参考图真正传递给模型**：不再是文本描述 URL，而是实际的图片数据
2. ✅ **提示词更简洁明确**：强调"EXACT SAME character"，只改变服装
3. ✅ **错误处理**：如果参考图下载失败，会降级为无参考图模式
4. ✅ **日志清晰**：可以看到参考图是否成功下载和转换
5. ✅ **兼容性**：Stable Diffusion 等不支持参考图的模型会显示警告并忽略该参数
