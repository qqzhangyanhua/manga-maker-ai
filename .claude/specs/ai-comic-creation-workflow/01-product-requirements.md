## 🎯 项目背景

### 当前状态
Manga Maker AI 是一个成熟的 AI 创作平台，目前已实现：
- ✅ **漫画创作**: 90% 完成（故事→剧本→分镜→图片→排版）
- ⚠️ **小说创作**: 80% 完成（缺少导出、搜索、修订前端）
- ✅ **核心技术**: Next.js 14 + React 18 + TypeScript + Python FastAPI
- ✅ **AI 能力**: 多提供商 LLM + 统一图片生成队列
- ✅ **用户系统**: 算力管理 + 认证授权

### 核心问题
根据用户反馈和代码库分析，当前存在以下问题：

**1. 使用体验问题** ⭐⭐⭐⭐⭐
- **操作流畅度不足**: 部分功能缺少快捷操作
- **反馈不及时**: 长时间操作缺少进度提示
- **学习曲线陡峭**: 新用户上手困难

**2. 功能完整性问题** ⭐⭐⭐⭐⭐
- **小说导出缺失**: 无法导出 TXT/Word/PDF
- **搜索能力不足**: 无法快速定位内容
- **修订功能未接入**: 后端已实现，前端缺失
- **批量操作有限**: 无法批量处理章节
- **工作流导出不完整**: 无法导出完整结果

**3. 长期发展问题** ⭐⭐⭐
- **可扩展性**: 需要支持更多格式和功能
- **用户留存**: 需要提升整体体验
- **竞争力**: 需要补齐行业标配功能

#### REQ-001: 小说导出功能 ⭐⭐⭐⭐⭐

**需求描述**:
用户完成小说创作后，需要导出为多种格式用于投稿、分享或备份。

**功能点**:
1. **导出格式支持**:
   - TXT 纯文本（UTF-8 编码）
   - Word (.docx) 格式
   - PDF 格式
   - EPUB 电子书（阶段三）

2. **导出配置**:
   - 选择导出范围（全部章节/指定章节）
   - 自定义格式（字体、字号、行距、页边距）
   - 包含/排除元数据（标题、作者、简介）
   - 章节分页设置

3. **导出流程**:
   - 点击"导出"按钮
   - 选择格式和配置
   - 显示导出进度
   - 下载完成后提示

**用户故事**:
- 作为小说作者，我希望导出 Word 格式，以便投稿到出版社
- 作为网文作者，我希望导出 TXT 格式，以便上传到网文平台
- 作为读者，我希望导出 PDF 格式，以便在平板上阅读

**验收标准**:
- [ ] 支持 TXT/Word/PDF 三种格式
- [ ] 导出内容完整，格式正确
- [ ] 导出进度实时显示
- [ ] 导出文件大小合理（< 10MB）
- [ ] 导出速度快（< 5s）
- [ ] 支持中文字符，无乱码

**技术实现**:
- **后端**: Python FastAPI
  - `python-docx` 生成 Word
  - `reportlab` 生成 PDF
  - `ebooklib` 生成 EPUB（阶段三）
- **前端**: React + TypeScript
  - 导出对话框组件 `ExportDialog`
  - 进度条组件 `ProgressBar`
  - 文件下载处理

**工作量估算**: 2-3 小时

#### REQ-002: 全文搜索 ⭐⭐⭐⭐

**需求描述**:
用户在长篇小说创作中，需要快速定位特定内容、角色或情节。

**功能点**:
1. **搜索范围**:
   - 章节标题
   - 章节内容
   - 角色名称
   - 世界观设定

2. **搜索功能**:
   - 关键词搜索
   - 正则表达式搜索（高级）
   - 模糊匹配
   - 全文高亮

3. **搜索结果**:
   - 显示匹配数量
   - 按相关度排序
   - 高亮显示关键词
   - 快速跳转到匹配位置

4. **搜索历史**:
   - 保存最近搜索
   - 快速重复搜索

**用户故事**:
- 作为小说作者，我希望搜索角色名称，以便查看该角色的所有出场章节
- 作为编辑，我希望搜索特定情节，以便检查前后一致性
- 作为作者，我希望搜索关键词，以便快速定位需要修改的内容

**验收标准**:
- [ ] 搜索速度快（< 1s）
- [ ] 搜索结果准确
- [ ] 支持中文分词
- [ ] 高亮显示清晰
- [ ] 支持跳转到匹配位置
- [ ] 搜索历史保存

**技术实现**:
- **后端**: Python FastAPI + PostgreSQL
  - PostgreSQL 全文搜索（`to_tsvector`）
  - 中文分词支持
  - API: `GET /projects/{id}/search?q=关键词`
- **前端**: React + TypeScript
  - 搜索对话框组件 `SearchDialog`
  - 搜索结果列表 `SearchResults`
  - 高亮组件 `Highlighter`

**工作量估算**: 1-2 小时

- [ ] 支持接受/拒绝操作
- [ ] 修订历史可查看
