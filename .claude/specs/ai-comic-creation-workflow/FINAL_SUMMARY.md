- **API**: RESTful + SSE（流式）

- **框架**: Next.js 14 (App Router)
- **UI 库**: React 18 + TypeScript
- **组件库**: shadcn/ui (Radix UI)
- **状态管理**: React Hooks
- **样式**: TailwindCSS

1. **PostgreSQL 全文搜索**

   - 中文数字转换

3. **SSE 流式返回**
   - 实时进度反馈
