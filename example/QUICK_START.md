# 🚀 快速开始 - 5分钟创建你的第一个AI漫画

## 第一步：配置API（2分钟）

### 1. 获取OpenAI API密钥

访问：https://platform.openai.com/api-keys

- 如果没有账号，先注册
- 点击 "Create new secret key"
- 复制密钥（格式：`sk-proj-...` 或 `sk-...`）

### 2. 配置密钥

打开 `js/config.js`，找到第4和第8行：

```javascript
// 分镜生成API密钥
STORYBOARD_API_KEY: 'sk-your-openai-api-key-for-gpt',

// 漫画生成API密钥
COMIC_API_KEY: 'sk-your-openai-api-key-for-dalle',
```

替换为你的密钥：

```javascript
STORYBOARD_API_KEY: 'sk-proj-abcdefg...xyz',
COMIC_API_KEY: 'sk-proj-abcdefg...xyz',  // 可以使用相同的密钥
```

**💡 提示：** 两个密钥可以使用相同的值，也可以使用不同账号的密钥来分散限额。

保存文件。

### 3. 充值账户（如需要）

- 新用户通常有免费额度
- 如果余额不足，需要充值
- 最低充值：$5
- 6格漫画成本：约$0.35

---

## 第二步：启动服务（1分钟）

### 方法1：Python（推荐）

```bash
cd example
python -m http.server 8000
```

### 方法2：Node.js

```bash
cd example
npx serve -p 8000
```

### 方法3：VS Code

右键 `index.html` → "Open with Live Server"

---

## 第三步：创作漫画（2分钟）

### 1. 打开浏览器

访问：http://localhost:8000/index.html

### 2. 上传照片

- 点击或拖拽上传
- 建议：清晰的人物照片
- 格式：JPG/PNG/WebP

### 3. 输入故事

复制以下示例（或自己创作）：

```
一只可爱的兔子第一次去健身房的故事：

1. 小兔推开健身房大门，好奇地四处张望
2. 开始尝试各种器械，虽然累但很开心
3. 坚持训练后，惊喜地发现肌肉变结实了
4. 遇到瓶颈，不知道如何继续进步
5. 得到AI教练的专业指导和鼓励
6. 经过系统训练，变成肌肉兔，自信满满

风格：可爱漫画风格，色彩鲜艳
```

### 4. 生成分镜

- 选择分镜数量：6格
- 点击"📝 生成分镜脚本"
- 等待10-30秒

### 5. 生成漫画

- 查看分镜脚本
- 点击"🎨 生成完整漫画"
- 等待1-3分钟（每格约10-30秒）

### 6. 下载保存

- 右键图片 → "图片另存为"
- 或点击"📥 下载完整漫画"

---

## 🎉 完成！

你的第一个AI漫画创作完成了！

## 💡 进阶技巧

### 故事创作提示

1. **结构清晰**
   ```
   开始 → 发展 → 转折 → 高潮 → 结局
   ```

2. **情绪变化**
   ```
   好奇 → 兴奋 → 满足 → 困惑 → 惊喜 → 自豪
   ```

3. **场景描述**
   ```
   具体场景 + 光线氛围 + 镜头角度
   ```

### 照片选择技巧

✅ **好照片：**
- 清晰度高
- 正面或侧面
- 光线充足
- 背景简洁

❌ **避免：**
- 模糊不清
- 多人合照
- 逆光背光
- 杂乱背景

### 分镜数量建议

| 分镜 | 场景 | 时间 | 成本 |
|------|------|------|------|
| 4格 | 简单故事 | 1分钟 | $0.20 |
| 6格 | 完整故事 | 2分钟 | $0.35 |
| 8格 | 复杂情节 | 3分钟 | $0.50 |

## ❓ 常见问题速查

### Q: API密钥无效？
```
检查清单：
□ 密钥完整复制（包括sk-前缀）
□ 没有多余空格
□ 账户有余额
□ 密钥未过期
```

### Q: 网络请求失败？
```
解决方案：
1. 检查网络连接
2. 查看浏览器控制台（F12）
3. 等待几分钟重试
4. 检查OpenAI服务状态
```

### Q: 图片不符合预期？
```
改进方法：
1. 更详细的故事描述
2. 使用更清晰的照片
3. 尝试gpt-4o模型
4. 增加场景细节描述
```

### Q: 成本太高？
```
节省成本：
1. 减少分镜数量（6→4）
2. 使用gpt-3.5-turbo
3. 使用dall-e-2
4. standard替代hd质量
```
