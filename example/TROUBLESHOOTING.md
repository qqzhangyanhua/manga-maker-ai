# 🔧 问题排查指南

## 常见问题

### ❌ 问题1：API返回文字描述而不是图片

**症状：**
```json
{
  "choices": [{
    "message": {
      "content": "好的，我将基于您提供的要求...以下是完整的2行 x 2列布局的4格漫画描述：..."
    }
  }]
}
```

**原因：**
- API模型认为你要的是漫画的设计方案/文字描述
- 提示词不够明确，没有强调"直接生成图片"

**解决方案：**

✅ **已修复！** 在提示词中添加了明确指令：

```javascript
// 单个分镜
let prompt = `请直接生成一张漫画图片，不要给我文字描述！\n\n`;
prompt += `要求：基于参考图片中的角色，创建一个${style}风格的漫画分镜。\n\n`;
// ...
prompt += `1. 直接生成图片，不要给我漫画的文字描述\n`;
prompt += `7. 请立即生成图片并返回`;

// 合并分镜
let prompt = `请直接生成一张完整的漫画图片，不要给我文字描述！\n\n`;
// ...
prompt += `1. 直接生成图片，不要给我漫画的文字描述或设计方案\n`;
prompt += `11. 请立即生成图片并返回，不要问我任何问题`;
```

**验证方法：**
1. 重新生成漫画
2. 查看浏览器控制台（F12）
3. 如果仍然返回文字描述，会看到警告：
   ```
   API返回了文字描述而不是图片: 好的，我将基于您提供的要求...
   ```

### ❌ 问题2：无法提取图片URL

**症状：**
```
错误：图片生成失败：响应中没有找到图片URL
```

**原因：**
- API返回的内容格式不正确
- 不包含 `![image](url)` 格式的图片链接

**检查方法：**

打开浏览器控制台（F12），查看日志：
```javascript
// 如果看到这个，说明API返回了文字
API返回了文字描述而不是图片: 好的，我将基于您提供的要求...

// 如果看到这个，说明格式不对
无法提取图片URL，API返回内容: ...
```

**解决方案：**

1. **检查提示词** - 确保包含"直接生成图片"
2. **检查API模型** - 确认模型支持图片生成
3. **查看完整响应** - 在控制台查看API返回的完整内容

---

### ❌ 问题3：参考图片特征不明显

**症状：**
生成的漫画角色与参考图片差异很大

**原因：**
- 参考图片质量不好
- 模型没有正确理解参考图片
- 提示词描述与参考图片冲突

**从你的例子看：**
```
提供的角色参考图片是**牛头人**，但您要求的故事情节主角是**"雪白垂耳兔"**
```

这说明：
1. ✅ API看到了参考图片（牛头人）
2. ❌ 但故事描述要求的是兔子
3. 结果：模型不知道听谁的

**解决方案：**

**A. 保持一致性：**
```javascript
// 如果参考图是兔子，故事也说兔子
上传图片：兔子照片
故事描述：一只可爱的白兔...
```

**B. 明确指令：**
```javascript
// 在提示词中强调
请基于参考图片中的角色（兔子），创建漫画...
使用参考图片中的角色外观特征...
```

**C. 选择合适的参考图：**
- ✅ 使用与故事主角相同类型的图片
- ✅ 图片清晰、特征明显
- ❌ 不要用完全不相关的图片

## ✅ 最佳实践

### 1. 提示词要明确

```javascript
// ❌ 不够明确
"创建一个漫画"

// ✅ 非常明确
"请直接生成一张漫画图片，不要给我文字描述！"
```

### 2. 参考图片要匹配

```javascript
// ❌ 不匹配
参考图：牛头人
故事：兔子的故事

// ✅ 匹配
参考图：兔子
故事：兔子的故事
```

### 3. 检查API响应格式

```javascript
// 预期的正确格式
{
  "content": "![image](https://xxx.png)"
}

// 错误的格式（文字描述）
{
  "content": "好的，我将创建一个漫画...以下是描述..."
}
```

### 4. 逐步测试

1. 先测试单个分镜（多张独立图）
2. 确认能正常生成图片
3. 再测试合并模式（单张图）

## 📋 问题检查清单

遇到问题时，按以下顺序检查：

- [ ] API密钥是否正确
- [ ] API地址是否正确
- [ ] 模型名称是否正确
- [ ] 是否上传了参考图片
- [ ] 参考图片与故事是否匹配
- [ ] 提示词是否包含"直接生成图片"
- [ ] 浏览器控制台是否有错误
- [ ] API响应是否包含图片URL
- [ ] 网络连接是否正常

## 🆘 获取帮助

### 1. 查看控制台日志

打开浏览器控制台（F12），查找：
- ❌ 红色错误信息
- ⚠️ 黄色警告信息
- 💬 API响应内容

### 2. 检查网络请求

在控制台的 Network 标签：
- 找到 `/chat/completions` 请求
- 查看 Request Payload（发送的内容）
- 查看 Response（返回的内容）

### 3. 测试API

使用curl直接测试：
```bash
curl https://duckcoding.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \

    "model": "gemini-2.5-flash-image",
    "messages": [{
      "role": "user",
      "content": "请直接生成一张可爱的兔子漫画图片"
    }]
  }'
```
