# 小说导出格式示例

本文档展示了新增的 Markdown 和 EPUB 导出格式的特性。

## Markdown 格式 (.md)

### 特点
- 使用标准 Markdown 语法
- 一级标题：小说标题
- 二级标题：章节标题
- 引用块：简介
- 分隔线：章节分隔
- 粗体：元数据标签

### 示例输出

```markdown
# 我的小说标题

> 这是一个关于冒险的故事...

**分类：** fantasy

**章节数：** 10

**导出时间：** 2026-01-05 12:00:00

---

## 第1章 启程

在一个阳光明媚的早晨，主人公踏上了冒险的旅程...

---

## 第2章 相遇

在森林深处，他遇到了一位神秘的旅者...

---
```

### 适用场景
- ✅ 使用 Typora、Obsidian 等工具编辑
- ✅ 提交到 GitHub 进行版本管理
- ✅ 转换为其他格式（HTML、PDF等）
- ✅ 在博客平台发布（支持 Markdown 的平台）

---

## EPUB 格式 (.epub)

### 特点
- 标准电子书格式
- 自动生成目录（TOC）
- 每章独立页面
- 支持电子阅读器原生渲染
- 响应式文字排版

### 内容结构
```
小说.epub
├── META-INF/
│   └── container.xml
├── OEBPS/
│   ├── content.opf (元数据)
│   ├── toc.ncx (目录)
│   ├── chapter-1.html
│   ├── chapter-2.html
│   └── ...
└── mimetype
```

### EPUB 元数据
- **标题：** 项目标题
- **作者：** "作者"（可自定义）
- **简介：** 项目描述
- **出版商：** "Generated by ComicAI"
- **目录标题：** "目录"

### 适用场景
- ✅ 在 Kindle、Apple Books、微信读书等阅读器阅读
- ✅ 上传到电子书平台（起点、掌阅、QQ阅读等）
- ✅ 分享给读者（通用格式）
- ✅ 移动设备离线阅读

## 导出 API 使用方法

### 请求示例

```bash
# Markdown 导出
curl -X POST http://localhost:3000/api/novel/export/projects/{projectId} \
  -H "Content-Type: application/json" \
  -d '{
    "format": "markdown",
    "config": {
      "include_metadata": true,
      "chapter_separator": true,
      "font_size": 12
    }
  }'

# EPUB 导出
curl -X POST http://localhost:3000/api/novel/export/projects/{projectId} \
  -H "Content-Type: application/json" \
  -d '{
    "format": "epub",
    "config": {
      "include_metadata": true,
      "chapter_separator": false,
      "font_size": 12
    }
  }'
```

### 响应示例

成功时返回文件下载：
- Content-Type: `text/markdown; charset=utf-8` (Markdown)
- Content-Type: `application/epub+zip` (EPUB)
- Content-Disposition: `attachment; filename="小说标题.md"` 或 `"小说标题.epub"`

失败时返回 JSON 错误：
```json
{
  "error": "项目中没有可导出的章节内容。请先在章节编辑器中编写或生成章节内容。"
}
```

## 前端使用

### ExportDialog 组件

新增的格式选项：

```tsx
<Select value={format} onValueChange={setFormat}>
  <SelectItem value="txt">纯文本 (TXT)</SelectItem>
  <SelectItem value="markdown">Markdown (MD)</SelectItem>
  <SelectItem value="epub">电子书 (EPUB)</SelectItem>
  <SelectItem value="docx">Word 文档 (DOCX) - 暂不支持</SelectItem>
  <SelectItem value="pdf">PDF 文档 - 暂不支持</SelectItem>
</Select>
```

### 下载处理

导出成功后自动触发浏览器下载：

```typescript
const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const a = document.createElement("a");
a.href = url;
a.download = `${projectTitle}.${format}`;
a.click();
```

## 技术实现

### Markdown
- **实现：** 纯字符串拼接，使用 TextEncoder
- **依赖：** 无（原生实现）
- **优势：** 轻量、快速、无需第三方库

### EPUB
- **实现：** 使用 `epub-gen-memory` 库
- **依赖：** `pnpm add epub-gen-memory`
- **特点：**
  - 内存生成（不写入磁盘）
  - 自动处理 HTML 转换
  - 标准 EPUB 2.0 格式
