## 🚀 快速开始

### 第一步：配置API密钥

打开 `js/config.js` 文件，修改以下内容：

```javascript
const CONFIG = {
  // 1. 填入你的OpenAI API密钥（必须）
  OPENAI_API_KEY: 'sk-your-openai-api-key-here',
  
  // 2. API基础地址（一般不需要修改）
  OPENAI_API_BASE: 'https://api.openai.com/v1',
  
  // 其他配置保持默认即可
};
```

**如何获取OpenAI API密钥？**
1. 访问 https://platform.openai.com/
2. 注册/登录账号
3. 进入 API Keys 页面
4. 点击 "Create new secret key"
5. 复制密钥并保存（只显示一次！）

### 第二步：启动本地服务器

由于浏览器安全限制，需要通过HTTP服务器访问。

**方法1：使用Python（推荐）**
```bash
# 进入example目录
cd example

# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**方法2：使用Node.js**
```bash
# 全局安装serve
npm install -g serve

# 启动服务器
cd example
serve -p 8000
```

**方法3：使用VS Code**
- 安装 "Live Server" 插件
- 右键 `index.html` → "Open with Live Server"

### 第三步：打开浏览器

访问：`http://localhost:8000/index.html`

### 3️⃣ 选择分镜数量

根据故事复杂度选择：

| 分镜数 | 适用场景 | 特点 |
|--------|---------|------|
| 4格 | 简单故事 | 快速、经济 |
| 6格 | 完整故事 | **推荐**，平衡 |
| 8格 | 复杂情节 | 详细、深入 |
| 9格 | 史诗故事 | 最详细，成本高 |

**建议：**
- 新手先尝试4-6格
- 熟练后可以尝试8-9格

**检查分镜：**

- 对话是否自然？

## ⚙️ 配置说明

### 基础配置

```javascript
// js/config.js

const CONFIG = {
  // OpenAI API密钥（必填）
  OPENAI_API_KEY: 'sk-xxxxxx',
  
  // API地址（通常不需要改）
  OPENAI_API_BASE: 'https://api.openai.com/v1',
  
  // 默认分镜数量
  DEFAULT_PANEL_COUNT: 6,
};
```

### 高级配置

#### 分镜生成配置

```javascript
// 使用的GPT模型
STORYBOARD_MODEL: 'gpt-4o', // 或 'gpt-4-turbo' / 'gpt-3.5-turbo'

// 创意程度 (0-1)
// 越高越有创意，但可能不太符合原意
STORYBOARD_TEMPERATURE: 0.7,
```

**模型对比：**

| 模型 | 效果 | 速度 | 成本 |
|-----|------|------|------|
| gpt-4o | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | $$$ |
| gpt-4-turbo | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | $$ |
| gpt-3.5-turbo | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | $ |

#### 漫画生成配置

```javascript
// 使用的DALL-E模型
COMIC_MODEL: 'dall-e-3', // 或 'dall-e-2'

// 图片尺寸
COMIC_SIZE: '1024x1024', // 或 '1792x1024' / '1024x1792'

// 图片质量
COMIC_QUALITY: 'standard', // 或 'hd'

// 图片风格
COMIC_STYLE: 'vivid', // 或 'natural'
```

**DALL-E 3 vs DALL-E 2：**

| 特性 | DALL-E 3 | DALL-E 2 |
|------|----------|----------|
| 质量 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 细节 | 更精细 | 一般 |
| 文字 | 支持较好 | 不支持 |
| 尺寸 | 3种选择 | 3种选择 |
| 价格 | $0.04起 | $0.02起 |

**尺寸选择：**
- `1024x1024` - 正方形（推荐）
- `1792x1024` - 横向宽幅
- `1024x1792` - 纵向长幅

**质量选择：**
- `standard` - 标准质量（推荐）
- `hd` - 高清质量（价格2倍）

## ❓ 常见问题

### Q1: API密钥无效？

**解决方法：**
1. 检查密钥是否完整复制
2. 确认没有多余空格
3. 检查账户是否有余额
4. 确认密钥未过期或被禁用

### Q2: 网络请求失败？

**可能原因：**
- 网络连接问题
- API服务器暂时不可用
- 请求被限流

**解决方法：**
- 检查网络连接
- 等待几分钟后重试
- 检查OpenAI状态页面

### Q3: 生成的图片不符合预期？

**改进建议：**
1. **更详细的描述**
   - 添加更多场景细节
   - 明确角色表情和动作
   
2. **调整参数**
   - 降低temperature（更保守）
   - 更换模型（gpt-4o效果更好）
   
3. **优化照片**
   - 使用更清晰的照片
   - 确保人物特征明显

### Q4: 角色一致性不好？

这是AI图像生成的常见挑战。改进方法：

1. **使用更好的照片**
   - 正面照效果最好
   - 特征明显的照片
   
2. **详细描述角色特征**
   - 在故事中重复提及角色特点
   - 使用明确的角色描述

3. **使用DALL-E 3**
   - 比DALL-E 2更稳定
   - 角色一致性更好

### Q5: 成本太高？

**节省成本的方法：**

1. **减少分镜数量**
   - 4格代替6格
   
2. **使用经济模型**
   - GPT-3.5-turbo代替GPT-4
   - DALL-E 2代替DALL-E 3
   
3. **优化质量设置**
   - standard代替hd
   - 1024x1024代替更大尺寸

**成本对比（6格漫画）：**

| 配置 | 成本 |
|------|------|
| GPT-4 + DALL-E 3 (HD) | ~$0.60 |
| GPT-4 + DALL-E 3 (标准) | ~$0.35 |
| GPT-3.5 + DALL-E 2 | ~$0.13 |

### Q6: 页面卡住不动？

**检查：**
1. 打开浏览器控制台（F12）查看错误
2. 检查网络请求是否成功
3. 确认API密钥配置正确

**解决：**
- 刷新页面重试
- 清除浏览器缓存
- 更换浏览器

### Q7: 图片加载很慢？

**正常现象：**
- DALL-E生成需要时间
- 每格10-30秒属于正常
- 网络速度也会影响

**如果特别慢：**
- 检查网络连接
- 尝试在网络较好时使用
- 考虑使用VPN

## 💡 最佳实践

### 写好故事描述的技巧

1. **结构清晰**
   - 明确起承转合
   - 每个情节点分开描述

2. **细节丰富**
   - 场景：具体位置、环境
   - 动作：详细的肢体语言
   - 表情：准确的情绪表达

3. **保持连贯**
   - 情节自然过渡
   - 情绪合理变化
   - 场景逻辑转换

4. **考虑视觉呈现**
   - 描述画面感强的场景
   - 避免纯心理描写
   - 多用动作代替对白

### 照片选择技巧

1. **人物清晰**
   - 分辨率足够
   - 五官清楚可见
   
2. **光线良好**
   - 避免逆光
   - 面部光线均匀
   
3. **背景简洁**
   - 纯色背景最佳
   - 避免杂乱背景

4. **表情自然**
   - 中性表情最好
   - 避免夸张表情

### 分镜设计原则

1. **节奏把控**
   - 前期铺垫
   - 中期高潮
   - 后期结局

2. **视觉变化**
   - 镜头远近交替
   - 场景定期切换
   - 角度多样化

3. **情绪曲线**
   - 起伏有致
   - 不要平铺直叙
   - 高潮点明确
