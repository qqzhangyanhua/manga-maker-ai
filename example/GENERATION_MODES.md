# 🎨 漫画生成模式说明

## 两种输出模式

### 1. 📄 合成为一张图（默认推荐）

**效果：** 将所有分镜拼接成一张完整的漫画图片，就像传统漫画书的一页。

**特点：**
- ✅ 一张图包含所有分镜
- ✅ 自动排版布局（网格）
- ✅ 分镜之间有边框分隔
- ✅ 每格有编号标识
- ✅ 便于分享和展示
- ✅ 统一的视觉效果

**布局规则：**
- 4格及以下：2列布局
- 5格及以上：3列布局
- 自动计算行数

**适合场景：**
- 📱 社交媒体分享
- 📖 完整故事展示
- 🖼️ 制作海报
- 📚 电子书/PDF

**示例布局：**
```
6格漫画 (2行×3列):
┌────┬────┬────┐
│ 1  │ 2  │ 3  │
├────┼────┼────┤
│ 4  │ 5  │ 6  │
└────┴────┴────┘
```

### 2. 🖼️ 多张独立图

**效果：** 每个分镜生成一张独立的图片。

**特点：**
- ✅ 每格单独一张图
- ✅ 可以单独使用
- ✅ 灵活性高
- ✅ 可以挑选使用
- ✅ 便于后期编辑

**适合场景：**
- ✏️ 需要后期编辑
- 🎬 制作动画/视频
- 📋 选择性使用部分分镜
- 🎨 混搭不同素材

## 使用流程

### 合成模式（推荐）

```
步骤1：生成分镜脚本
  ↓
步骤2：上传参考图片
  ↓
步骤3：选择"合成为一张图"（默认已选中）
  ↓
步骤4：点击"生成完整漫画"
  ↓
结果：获得一张包含所有分镜的完整漫画图
```

### 独立模式

```
步骤1：生成分镜脚本
  ↓
步骤2：上传参考图片
  ↓
步骤3：选择"多张独立图"
  ↓
步骤4：点击"生成完整漫画"
  ↓
结果：获得多张独立的分镜图片
```

## 技术实现

### 合成模式

**工作原理：**
1. 为每个分镜生成独立图片
2. 使用Canvas API将所有图片拼接
3. 添加边框和编号
4. 输出为单张PNG图片

**关键代码：** `comic-generator.js`
```javascript
async mergeImagesIntoComic(imageUrls, columns = 2) {
  // 1. 加载所有图片
  // 2. 创建Canvas画布
  // 3. 计算布局
  // 4. 绘制图片和边框
  // 5. 添加分镜编号
  // 6. 导出为base64
}
```

### 独立模式

**工作原理：**
1. 逐个生成每格分镜
2. 显示为独立的图片列表
3. 每张图片可单独下载

## 成本说明

**两种模式的API调用成本相同！**

无论选择哪种模式，都需要为每个分镜调用一次图像生成API：

- 6格漫画 = 6次API调用
- 使用gemini-2.5-flash-image
- 成本取决于API提供商的定价

**合成模式的额外处理：**
- 在浏览器端完成（Canvas API）
- 不产生额外API费用
- 瞬间完成

## 常见问题

### Q: 合成模式会降低图片质量吗？

A: 不会。合成使用Canvas API进行无损拼接，保持原始图片质量。

### Q: 可以更改合成的布局吗？

A: 目前布局是自动计算的（4格以下2列，5格以上3列）。未来版本会添加自定义布局选项。

### Q: 独立模式可以批量下载吗？

A: 目前需要逐张下载。未来版本会添加批量下载功能。

### Q: 合成后还能获得单独的分镜吗？

A: 不能。如果需要单独的分镜，请选择"多张独立图"模式。

### Q: 两种模式可以切换吗？

A: 可以。生成后如果不满意，可以重新选择模式并重新生成（会重新调用API）。

## 技术细节

### Canvas合成算法

```javascript
// 计算画布尺寸
canvasWidth = columns × imageWidth + (columns + 1) × padding
canvasHeight = rows × imageHeight + (rows + 1) × padding

// 每格位置
x = padding + col × (imageWidth + padding)
y = padding + row × (imageHeight + padding)
```

### 边框和装饰

- 边框颜色：#E0E0E0
- 边框宽度：2px
- 分镜间距：20px
- 编号颜色：rgba(102, 126, 234, 0.9)
- 编号字体：bold 24px Arial
